# F-0005: Acceptance Criteria Files

## Acceptance Criteria

- [ ] AC1: spec/acceptance/ directory exists in Core+PM projects
- [ ] AC2: Each feature F-#### has corresponding spec/acceptance/F-####.md
- [ ] AC3: Acceptance file template defines required structure
- [ ] AC4: Acceptance files have checkable criteria (- [ ] format)
- [ ] AC5: validate_specs.py warns about features missing acceptance files
- [ ] AC6: FEATURES.md links to acceptance files

## Verification

- **Automated**:
  - Scaffold creates spec/acceptance/ directory
  - Template exists for acceptance files
  - validate_specs.py checks for missing acceptance files
- **Manual**: Agent creates acceptance file before implementing feature
- **Profile**: Core+PM only
