# F-0028: Continue-Here Generator

## Status: DEPRECATED (v0.12.0)

**Superseded by**: Project Phase tracking in STATUS.md/PRODUCT.md

The separate `.continue-here.md` file was redundant with existing mechanisms:
- `STATUS.md` / `PRODUCT.md` now includes "Project Phase" section
- `session_start.md` checklist guides agents to read project state directly
- `WIP.md` handles interrupted work detection

The `continue_here.py` script is kept for backwards compatibility but deprecated.

---

## Original Acceptance Criteria (Historical)

- [x] AC1: continue_here.py script exists
- [x] AC2: Script generates context for next session
- [x] AC3: Output includes: what was being worked on, next steps
- [x] AC4: Output includes: relevant file locations
- [x] AC5: Can be run at session end to prepare handoff
- [x] AC6: Output is concise and actionable

## Replacement

Session continuity is now handled by:
1. **Project Phase** in STATUS.md/PRODUCT.md: `discovery | building`
2. **session_start.md checklist**: Agent reads STATUS.md directly
3. **WIP.md**: Tracks interrupted work
