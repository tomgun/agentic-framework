# F-0139: Doc Lifecycle System

## Tests

### Structural (validate_framework.sh)
- docs.sh exists and is executable
- doc_types.md exists with all 8 built-in types
- ag.sh has `cmd_docs` function and `docs)` case
- ag.sh wires docs.sh into cmd_done (after docs_gate)
- STACK.template.md has `## Docs` section
- scaffold.sh references `## Docs`
- auto_orchestration.md mentions doc lifecycle
- documentation-agent.md has structured registry mode
- STACK.md (framework dogfooding) has populated `## Docs` section
- docs.sh --list runs without error on framework project

### Behavioral (LLM tests)
- LLM-064: Agent knows about `ag docs` command and doc registry in STACK.md
- LLM-065: Agent runs doc lifecycle at feature completion (ag done triggers docs)

## Acceptance Criteria

### AC-1: Doc Registry in STACK.md
- **Given** a project with STACK.md
- **When** user adds `- doc: docs/lessons.md | lessons | feature_done` to `## Docs` section
- **Then** `docs.sh --list` shows the entry; no .agentic/ files need editing

### AC-2: docs.sh --list parses registry
- **Given** a STACK.md with 3 doc entries in `## Docs`
- **When** running `docs.sh --list`
- **Then** output shows a formatted table of (path, type, trigger) for all 3 entries

### AC-3: docs.sh --trigger filters correctly
- **Given** registry with `changelog | pr` and `lessons | feature_done`
- **When** running `docs.sh --trigger feature_done`
- **Then** only `lessons` entry is included in output (changelog skipped)

### AC-4: docs.sh --check dry run
- **Given** registry with entries and a manifest F-0001
- **When** running `docs.sh --check --manifest F-0001`
- **Then** output shows what would be drafted but no files are modified

### AC-5: Empty registry
- **Given** STACK.md with no `## Docs` section or empty section
- **When** running `docs.sh --list` or `docs.sh --trigger feature_done`
- **Then** prints "No docs registered in STACK.md ## Docs" and exits 0

### AC-6: ag done wiring
- **Given** formal profile with populated `## Docs` registry
- **When** running `ag done F-####`
- **Then** docs.sh --trigger feature_done fires after docs_gate; docs.sh --trigger pr fires only in formal profile

### AC-7: Upgrade resilience
- **Given** a project with custom entries in STACK.md `## Docs`
- **When** .agentic/ directory is replaced (upgrade)
- **Then** STACK.md `## Docs` is intact; new docs.sh reads it correctly

### AC-8: ag docs command
- **Given** framework is installed
- **When** running `ag docs --list`
- **Then** shows registry from STACK.md; `ag help` includes docs command
