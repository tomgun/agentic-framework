# F-0084: Untracked Files Protection - Acceptance Criteria

## AC-001: Check Script Exists

**Given** the framework  
**When** checking `.agentic/tools/`  
**Then** `check-untracked.sh` exists and is executable with:
- Detection of untracked files in project directories
- List of directories to check (assets, src, tests, spec, docs, etc.)
- Warning output (not blocking)
- Exit code 2 for warning, 0 for clean

## AC-002: Pre-Commit Hook Integration

**Given** `.agentic/hooks/pre-commit-check.sh`  
**When** running the script  
**Then** it includes untracked files check as one of its checks (6/6) with:
- Warning message about untracked files
- List of untracked files in project directories
- Suggestion to git add or .gitignore
- Non-blocking (warning only)

## AC-003: Session End Checklist Updated

**Given** `.agentic/checklists/session_end.md`  
**When** reading the "Code State Clean" section  
**Then** it includes:
- Check for untracked files
- Command to run: `git status --short | grep '??'`
- Warning about deployment impact

## AC-004: Before Commit Checklist Updated

**Given** `.agentic/checklists/before_commit.md`  
**When** reading the "Final Checks" section  
**Then** it includes:
- Untracked files check as CRITICAL
- Specific directories to check
- Command to verify

## AC-005: Agent Guidelines Updated

**Given** `agent_operating_guidelines.md`  
**When** reading the "After creating any file" section  
**Then** it includes:
- "ALWAYS git add the new file"
- Warning about untracked files = missing from deployment
- Before committing: review untracked files
