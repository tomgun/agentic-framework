# F-0037: Project Health Monitoring - Acceptance Criteria

## AC-001: Script Exists and Runs

**Given** the framework  
**When** running `bash .agentic/tools/project-health.sh`  
**Then** script executes without error and produces output

## AC-002: Pipeline Status Check

**Given** a project with `.agentic/pipeline/F-0042-pipeline.md`  
**When** running project-health.sh  
**Then** output shows:
- Number of active pipelines
- Current agent for each pipeline
- Phase status (in_progress, blocked, complete)
- Warning for stalled pipelines (>2 hours without update)

## AC-003: Feature Status Summary

**Given** a project with `spec/FEATURES.md`  
**When** running project-health.sh  
**Then** output shows:
- Count of shipped features
- Count of in_progress features
- Count of planned features

## AC-004: Documentation Currency

**Given** a project with JOURNAL.md, STATUS.md, CONTEXT_PACK.md  
**When** running project-health.sh  
**Then** output shows:
- Age of each document (days since last update)
- Warning if documents are stale (configurable thresholds)

## AC-005: Human Needed Items

**Given** a project with HUMAN_NEEDED.md containing open items  
**When** running project-health.sh  
**Then** output shows:
- Count of open items requiring human attention
- Warning if items exist

## AC-006: Verbose Mode

**Given** project-health.sh  
**When** running with `--verbose` flag  
**Then** additional details are shown:
- Specific stalled pipelines
- Specific outdated documents
- First 5 human-needed items

## AC-007: Summary Output

**Given** project-health.sh output  
**When** viewing the end of output  
**Then** a summary shows:
- Overall health status (GOOD, WARNINGS, ISSUES)
- Count of warnings and issues

## Verification

- [ ] AC-001: Script runs without error
- [ ] AC-002: Pipeline status is tracked
- [ ] AC-003: Feature counts are shown
- [ ] AC-004: Document age is checked
- [ ] AC-005: HUMAN_NEEDED items are counted
- [ ] AC-006: --verbose shows more detail
- [ ] AC-007: Summary provides quick status
