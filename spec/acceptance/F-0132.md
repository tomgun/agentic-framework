# F-0132: Programmatic Spec-First Gate

## Acceptance Criteria

### ag plan gate
- [ ] `ag plan F-XXXX` checks FEATURES.md for F-XXXX entry before proceeding
- [ ] If F-XXXX not found, prints error and exits (does not enter plan mode)
- [ ] `ag plan` without F-XXXX still works (for ad-hoc planning without feature tracking)
- [ ] Gate only active when `feature_tracking=yes`

### ag implement gate
- [ ] `ag implement F-XXXX` checks FEATURES.md for F-XXXX entry
- [ ] `ag implement F-XXXX` checks `spec/acceptance/F-XXXX.md` exists
- [ ] If either missing, prints error with instructions to create them
- [ ] Gate only active when `feature_tracking=yes`

### Session-start awareness
- [ ] Session-start checklist mentions: "if in-progress work exists, verify F-XXXX has acceptance criteria"
- [ ] `ag start` warns if active branch has no associated F-XXXX (heuristic: branch name contains F-XXXX pattern)

### Escape hatch
- [ ] `SKIP_SPEC_CHECK=1 ag implement F-XXXX` bypasses the gate (with warning)
- [ ] Skip reason is logged

### Tests
- [ ] Framework validation test: `ag plan F-9999` fails when F-9999 not in FEATURES.md
- [ ] Framework validation test: `ag implement F-9999` fails when no acceptance file
- [ ] Framework validation test: gate inactive when `feature_tracking=no`
