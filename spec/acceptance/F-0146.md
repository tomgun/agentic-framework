# F-0146: Project-Specific Agent Generation (Layer A)

## Acceptance Criteria

### Specialization Rules
- [ ] `.agentic/agents/specialization/*.conf` files exist (react, fastapi, django, go, godot)
- [ ] Each has detect patterns, agent overrides (purpose_suffix, instructions, key_dirs)
- [ ] Flat key=value format parseable with grep/sed
- [ ] Detection methods: file presence (`detect_files`), package.json deps (`detect_package`), pyproject.toml/requirements.txt (`detect_pyproject`), STACK.md labels (`detect_label`)

### Generation Pipeline
- [ ] `generate-project-agents.sh` detects stack from STACK.md + file presence + package deps
- [ ] Matches specialization rules from detection patterns
- [ ] Applies rules to generic agents → project-specific agents in `subagents-project/`
- [ ] Output has `<!-- AUTO-GENERATED -->` header
- [ ] `<!-- CUSTOMIZED -->` files are skipped on regeneration
- [ ] `--dry-run` shows what would be generated without writing
- [ ] `--clean` removes auto-generated agents (preserves CUSTOMIZED)

### Skills Integration
- [ ] `generate-skills.sh` processes both hand-crafted skills and `subagents-project/`
- [ ] Project agents append project-specific rules to existing skills via `<!-- PROJECT-RULES -->` markers
- [ ] Agent type → skill mapping: implementation → implementing-features, test → writing-tests, review → reviewing-code

### CLI Integration
- [ ] `ag agents generate` runs the generation pipeline
- [ ] `ag agents list` shows current project agents
- [ ] `ag agents clean` removes auto-generated agents
- [ ] `suggest-agents.sh` redirects to `ag agents generate`

### Init Integration
- [ ] `scaffold.sh` hooks generation after discovery (both Discovery and Formal profiles)
- [ ] Generation runs only when specialization rules exist

### Output Quality
- [ ] Generated content is LLM-optimized: dense, action-oriented, token-efficient
- [ ] Uses project's actual file paths and patterns from specialization rules
- [ ] No prose paragraphs — bullet points and declarative rules only

### Tests
- [ ] `test_generate_project_agents.sh` covers detection, generation, AUTO-GENERATED marker, CUSTOMIZED guard, multi-stack
- [ ] `validate_framework.sh` passes
