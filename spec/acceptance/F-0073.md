# F-0073: Human-Agent Collaboration - Acceptance Criteria

**Feature**: Both humans and agents work on project truth

**Version**: 0.1.0

---

## Acceptance Criteria

### Dual Editing Supported

- [x] **AC-001**: Spec files are plain markdown (human-readable)
- [x] **AC-002**: Humans can directly edit FEATURES.md, PRODUCT.md, etc.
- [x] **AC-003**: Agents can update specs (same format humans use)
- [x] **AC-004**: No proprietary formats that lock out humans

### Clear Roles

- [x] **AC-010**: Documentation explains human role (decisions, priorities)
- [x] **AC-011**: Documentation explains agent role (implementation, doc sync)
- [x] **AC-012**: Boundaries are clear (when to escalate)

### Human Escalation

- [x] **AC-020**: HUMAN_NEEDED.md exists for blocking issues
- [x] **AC-021**: Agents document blockers IMMEDIATELY (not just chat)
- [x] **AC-022**: Clear format for human action items

### Human Tools

- [x] **AC-030**: MANUAL_OPERATIONS.md documents token-free queries
- [x] **AC-031**: Scripts have human-usable help messages
- [x] **AC-032**: Reports can be generated without agents

### Agent Guidelines

- [x] **AC-040**: agent_operating_guidelines.md explains collaboration
- [x] **AC-041**: Agents know to check for human edits to specs
- [x] **AC-042**: Agents preserve human-added content when updating

---

## Validation Commands

```bash
# Check human-readable formats
file .agentic/spec/FEATURES.template.md  # Should be text/markdown

# Check HUMAN_NEEDED template
cat .agentic/spec/HUMAN_NEEDED.template.md

# Check manual operations guide
cat .agentic/MANUAL_OPERATIONS.md

# Check collaboration in guidelines
grep -i "human" .agentic/agents/shared/agent_operating_guidelines.md | head -10
```

## Test Scenarios

### Scenario 1: Human Adds Feature

**Given**: Human edits FEATURES.md directly, adds new feature
**When**: Agent starts session
**Then**: Agent sees new feature, can implement it

### Scenario 2: Agent Hits Blocker

**Given**: Agent needs API key to continue
**When**: Agent identifies blocker
**Then**: Agent adds to HUMAN_NEEDED.md, human can see and resolve

### Scenario 3: Human Checks Status

**Given**: Human wants to know project state
**When**: Human reads STATUS.md and JOURNAL.md
**Then**: Human understands current state without asking agent

### Scenario 4: Dual Editing

**Given**: Human edited acceptance criteria
**When**: Agent updates feature status
**Then**: Agent preserves human's acceptance criteria, only updates status field
