# F-0127: Tip of the Day

## Acceptance Criteria

### Random Tip Display
- [x] `ag start` displays one random tip per session
- [x] Tip pool contains at least 10 tips covering different `ag` commands
- [x] Tips use dim formatting (non-intrusive, below main dashboard content)
- [x] Tips are actionable — each mentions a specific command the user can run

### Tip Content Coverage
- [x] Covers `ag sync`, `ag plan`, `ag trace`, `ag test llm`, `ag verify`, `ag specs`, `ag tools`, `ag approve-onboarding`
- [x] Tips describe what the command does, not just the command name

### Greeting Template
- [x] `session_start.md` greeting template includes tip placeholder

### Design Constraints
- [x] Zero token cost — tips are static strings in `ag.sh`, not generated by LLM
- [x] Uses `$RANDOM` for selection — no external dependencies
- [x] Tip appears before "Ready to work" line (natural reading order)
