# NFR-0002: Token Budget Compliance - Acceptance Criteria

**NFR**: Subagent context injection must stay within the configured token budget per role

**Category**: performance

---

## Acceptance Criteria

### Measurement

- [x] **AC-001**: `context-for-role.sh` reports token count for each role context
- [x] **AC-002**: Token count stays within budget defined in context manifests

### Enforcement

- [x] **AC-010**: `context-for-role.sh` warns at runtime when over budget
- [x] **AC-011**: `tests/test_nfr_validation.py` validates NFR entry fields
- [x] **AC-012**: `doctor.py` NFR content validation verifies test paths exist

### Scope

- [x] **AC-020**: Applies to all subagent context manifests in `.agentic/agents/*/context-manifests/`
- [x] **AC-021**: Each role's manifest declares its own token budget

---

## Validation Commands

```bash
# Check token counts for all roles
for role in review test implementation; do
  bash .agentic/tools/context-for-role.sh "$role"
done

# Run NFR validation tests
python -m pytest tests/test_nfr_validation.py -v

# Run NFR validator via doctor
python .agentic/tools/doctor.py --check nfr
```
