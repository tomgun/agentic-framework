# F-0002: Profile Selection (Core vs Core+PM)

## Acceptance Criteria

- [ ] AC1: scaffold.sh accepts `--profile core` and `--profile core+product` flags
- [ ] AC2: AGENTIC_PROFILE environment variable overrides default
- [ ] AC3: Core profile creates: STACK.md, CONTEXT_PACK.md, OVERVIEW.md, JOURNAL.md, HUMAN_NEEDED.md

- [ ] AC7: Invalid profile value produces clear error message
