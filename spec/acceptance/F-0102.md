# F-0102: Modular Guidelines for Token Efficiency

## Description
Split large agent_operating_guidelines.md into lazy-loaded modules. Agents load only guidelines relevant to their current task.

## Acceptance Criteria

### A-0102-01: Guidelines Directory Exists
- [ ] `.agentic/agents/shared/guidelines/` directory exists
- [ ] README.md explains module purposes and when to load each

### A-0102-02: Core Modules Extracted
- [ ] `anti-hallucination.md` - core rules for avoiding fabrication
- [ ] `token-efficiency.md` - scripts, delegation, context optimization
- [ ] `small-batch.md` - one feature at a time, commit limits
- [ ] `wip-tracking.md` - work-in-progress, recovery
- [ ] `multi-agent.md` - coordination, AGENTS_ACTIVE.md, worktrees

### A-0102-03: Modules Are Self-Contained
- [ ] Each module can be read independently
- [ ] No circular dependencies between modules
- [ ] Each module has clear "When to Use" section

### A-0102-04: Token Savings Documented
- [ ] README.md documents expected token savings
- [ ] Before: ~12,800 tokens (full guidelines)
- [ ] After: ~2,000 tokens (core + 1 module)
- [ ] ~84% reduction for typical tasks

### A-0102-05: CLAUDE.md Remains Self-Contained
- [ ] CLAUDE.md is NOT replaced by module references
- [ ] CLAUDE.md contains full essential content (bootstrap requirement)
- [ ] See ADR-001 for rationale

## Validation
```bash
# Check guidelines directory exists
test -d .agentic/agents/shared/guidelines && echo "PASS: Guidelines directory exists"

# Check all modules exist
for module in anti-hallucination token-efficiency small-batch wip-tracking multi-agent; do
  test -f ".agentic/agents/shared/guidelines/${module}.md" && echo "PASS: ${module}.md exists"
done

# Check README exists
test -f .agentic/agents/shared/guidelines/README.md && echo "PASS: Guidelines README exists"
```

## Notes
- Modules are for LAZY LOADING by agents that don't need full context
- CLAUDE.md bootstrap remains self-contained (ADR-001)
- agent_operating_guidelines.md remains the comprehensive reference
