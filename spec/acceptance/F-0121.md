# F-0121: Tool-Specific Instructions Parity

## Description

Ensure Cursor, Codex, and Copilot templates in `.agentic/agents/` have feature parity with Claude template for enforced gates.

## Acceptance Criteria

- [ ] **AC-001**: All 4 templates have 6-gate table with identical gate names (Acceptance criteria, WIP before commit, Test execution, Complexity limits, Pre-commit checks, Feature status)
- [ ] **AC-002**: All templates have "Small Batch Development" section with "TOO BIG" response pattern
- [ ] **AC-003**: All templates document escape hatches (`SKIP_TESTS=1`, `SKIP_COMPLEXITY=1`)
- [ ] **AC-004**: All templates have "implement entire" / "full system" in trigger words table
- [ ] **AC-005**: `/CODEX.md` extends template (follows `/CLAUDE.md` pattern, not a stub)
- [ ] **AC-006**: `tests/validate_framework.sh` includes gate parity check

## Definition of Parity

| Required Element | Description |
|------------------|-------------|
| 6-gate table | All 6 gates from Claude template present |
| Escape hatches | `SKIP_TESTS=1`, `SKIP_COMPLEXITY=1` documented |
| Small batch development | "TOO BIG" trigger, max 5-10 files rule |
| "implement entire" trigger | Trigger word for scope detection |

## Out of Scope

These elements already exist in Codex/Copilot templates:
- Token-efficient scripts
- Session protocols
- Agent boundaries

## Verification

```bash
# Gate count check (should return 6 for each template)
for f in .agentic/agents/claude/CLAUDE.md .agentic/agents/codex/codex-instructions.md .agentic/agents/copilot/copilot-instructions.md .agentic/agents/cursor/cursorrules.txt; do
  echo "$f: $(grep -c "^\| " "$f" | head -1) table rows"
done

# Run framework validation
bash tests/validate_framework.sh
```
