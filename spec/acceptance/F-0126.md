# F-0126: Discoverability Reminders

## Acceptance Criteria

### `ag start` Output
- [x] Dim "Remind user" line at bottom of `ag start` output shows `ag plan` and `ag sync`
- [x] Yellow sync probe line appears when `ag sync --quiet` detects issues
- [x] Probe line includes actionable "Run `ag sync` to auto-fix" suggestion

### Greeting Template
- [x] `session_start.md` greeting template includes "Available workflows" line with `ag plan` and `ag sync`
- [x] Template serves as guidance for agent's natural-language greeting

### Quick Commands
- [x] Both `CLAUDE.md` files (root + template) include `ag sync` in Quick Commands line

### Design Constraints
- [x] Reminders are placed where agents actually look (dashboard output), not just in instruction files
- [x] Dim formatting ensures reminders don't dominate the output
- [x] Sync probe only shows when issues exist (no noise when clean)
