# F-0002: List tasks

## User story
As a user, I want to see all my tasks so I know what's pending.

## Acceptance criteria

### AC1: List all tasks
**Given:** Tasks exist  
**When:** User lists tasks  
**Then:** All tasks are displayed with ID, title, and completion status

### AC2: Empty list handling
**Given:** No tasks exist  
**When:** User lists tasks  
**Then:** "No tasks found" message is shown

### AC3: Completed tasks shown
**Given:** Some tasks are completed  
**When:** User lists tasks  
**Then:** Completed tasks are marked with ✓

## Test coverage

## Implementation
- File: `task_manager.py`
- Function: `TaskManager.list_tasks()`

## Notes
- Returns a copy of tasks list (not direct reference)
- No filtering by completion status (all tasks shown)
