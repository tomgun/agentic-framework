# F-0001: Add tasks

## User story
As a user, I want to add tasks so I can track what I need to do.

## Acceptance criteria

### AC1: Add task with title
**Given:** User provides a task title  
**When:** User adds a task  
**Then:** 
- Task is created with unique ID
- Task is marked as not completed
- Task is persisted to storage
- Task ID is returned

### AC2: Task title is required
**Given:** No title provided  
**When:** User tries to add a task  
**Then:** Error (handled by CLI validation)

### AC3: Multiple tasks can be added
**Given:** Multiple tasks are added  
**When:** Tasks are listed  
**Then:** All tasks are shown
