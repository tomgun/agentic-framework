# F-0004: Filter tasks

## User story
As a user, I want to filter my task list so I can focus on active or completed tasks.

## Acceptance criteria

### AC1: Three filter options
**Given:** Tasks exist (some active, some completed)  
**When:** User views filter controls  
**Then:** 
- Three buttons shown: "All", "Active", "Completed"
- Current filter is highlighted

### AC2: Filter "All" shows everything
**Given:** Filter is set to "All"  
**When:** User views task list  
**Then:** All tasks are shown (both active and completed)

### AC3: Filter "Active" shows incomplete tasks
**Given:** Filter is set to "Active"  
**When:** User views task list  
**Then:** Only incomplete tasks are shown

### AC4: Filter "Completed" shows complete tasks
**Given:** Filter is set to "Completed"  
**When:** User views task list  
**Then:** Only completed tasks are shown

### AC5: Filter persists
**Given:** User sets filter to "Active"  
**When:** User refreshes page  
**Then:** Filter remains "Active" (persisted to localStorage)

### AC6: Filter counts shown
**Given:** Tasks exist  
**When:** User views filters  
**Then:** Each filter shows count (e.g., "All (10)", "Active (7)", "Completed (3)")
