# F-0005: Delete tasks

## User story
As a user, I want to delete tasks I no longer need so I can keep my list clean.

## Acceptance criteria

### AC1: Delete button visible
**Given:** Task exists  
**When:** User hovers over task  
**Then:** Delete button (trash icon) appears

### AC2: Confirmation dialog
**Given:** User clicks delete button  
**When:** Dialog appears  
**Then:** 
- Message: "Delete task '[title]'?"
- Two buttons: "Cancel" and "Delete"

### AC3: Cancel preserves task
**Given:** Confirmation dialog is open  
**When:** User clicks "Cancel"  
**Then:** 
- Dialog closes
- Task remains in list

### AC4: Confirm deletes task
**Given:** Confirmation dialog is open  
**When:** User clicks "Delete"  
**Then:** 
- Task is removed from list
- Changes persisted to storage
- Fade-out animation plays

### AC5: Keyboard accessible
**Given:** Task row has focus  
**When:** User presses Delete key  
**Then:** Confirmation dialog opens

### AC6: Screen reader accessible
**Given:** User navigates with screen reader  
**When:** Delete button is focused  
**Then:** Screen reader announces "Delete task [title]"
