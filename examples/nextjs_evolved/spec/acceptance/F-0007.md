# F-0007: Server Component optimization

## Technical Story  
As a developer, I want to optimize bundle size by converting static components to React Server Components.

## Acceptance criteria

### AC1: TaskList is Server Component
**Given:** TaskList component  
**When:** Developer reviews code  
**Then:** 
- No 'use client' directive in TaskList.tsx
- Component runs on server
- No hydration needed

### AC2: Client boundary at TaskRow
**Given:** TaskRow needs interactivity  
**When:** Developer reviews code  
**Then:** 
- 'use client' directive in TaskRow.tsx
- TaskRow is Client Component
- Receives props from Server Component parent

### AC3: Bundle size reduced
**Given:** Production build  
**When:** Build completes  
**Then:** 
- Bundle size reduced by ~50kb
- Still under 500kb threshold
- No functionality lost

### AC4: All tests still pass
**Given:** Refactored components  
**When:** Test suite runs  
**Then:** 
- All unit tests pass
- All integration tests pass
- All E2E tests pass

### AC5: No performance regression
**Given:** Refactored app  
**When:** Lighthouse CI runs  
**Then:** 
- Performance score ≥91 (not worse)
- First Contentful Paint improved
- Time to Interactive same or better
