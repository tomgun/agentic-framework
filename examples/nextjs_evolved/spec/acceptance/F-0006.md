# F-0006: E2E test infrastructure

## Technical Story
As a developer, I need E2E test infrastructure so I can catch user flow bugs before production.

## Acceptance criteria

### AC1: Playwright installed and configured
**Given:** Project repo  
**When:** Developer runs `npm install`  
**Then:** 
- Playwright dependencies installed
- `playwright.config.ts` configured
- Browsers installed

### AC2: Tests run locally
**Given:** Dev server is running  
**When:** Developer runs `npm run test:e2e`  
**Then:** 
- Playwright starts dev server automatically
- Tests execute in headless browsers
- Results displayed in terminal

### AC3: Tests run in CI
**Given:** Code pushed to GitHub  
**When:** CI pipeline executes  
**Then:** 
- Playwright tests run
- Failures block merge
- Screenshots/videos captured on failure

### AC4: Critical paths covered
**Given:** E2E tests exist  
**When:** Developer reviews test suite  
**Then:** At least these flows have tests:
- Add task (F-0001)
- Complete task (F-0003)
- Filter tasks (F-0004)
- Delete task (F-0005)

### AC5: Test codegen available
**Given:** Playwright installed  
**When:** Developer runs `npx playwright codegen`  
**Then:** 
- Browser opens
- Actions recorded automatically
- Test code generated
