# F-0010: Multi-tab synchronization

## User story
As a user with multiple tabs open, I want changes in one tab to appear in other tabs so my data stays consistent.

## Acceptance criteria

### AC1: Add task syncs to other tabs
**Given:** User has 2 tabs open  
**When:** User adds task in Tab A  
**Then:** 
- Task appears in Tab A immediately
- Task appears in Tab B within 1 second
- No page refresh needed

### AC2: Complete task syncs
**Given:** User has 2 tabs open  
**When:** User completes task in Tab B  
**Then:** 
- Task marked complete in Tab B immediately
- Task marked complete in Tab A within 1 second

### AC3: Delete task syncs
**Given:** User has 2 tabs open  
**When:** User deletes task in Tab A  
**Then:** 
- Task removed from Tab A immediately
- Task removed from Tab B within 1 second

### AC4: Filter state syncs
**Given:** User has 2 tabs open  
**When:** User changes filter in Tab A  
**Then:** Filter changes in Tab B as well

### AC5: No sync conflicts
**Given:** User edits same task in 2 tabs simultaneously  
**When:** Both edits complete  
**Then:** 
- Last write wins (no data corruption)
- No error shown to user
