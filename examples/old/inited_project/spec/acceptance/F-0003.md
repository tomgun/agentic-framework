# F-0003: Complete tasks

## User story
As a user, I want to mark tasks as complete so I can track progress.

## Acceptance criteria

### AC1: Complete existing task
**Given:** Task exists with ID  
**When:** User completes task by ID  
**Then:**
- Task is marked as completed
- Changes are persisted
- Success confirmation shown

### AC2: Handle nonexistent task
**Given:** Task ID doesn't exist  
**When:** User tries to complete task  
**Then:**
- Returns false/error
- "Task not found" message shown

### AC3: Already completed task
**Given:** Task is already completed  
**When:** User completes it again  
**Then:** No error (idempotent operation)

## Implementation
- File: `task_manager.py`

## Notes
- Completion is idempotent (can complete multiple times)
- Returns boolean for success/failure
