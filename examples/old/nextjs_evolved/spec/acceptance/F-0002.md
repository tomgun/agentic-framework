# F-0002: List tasks

## User story
As a user, I want to see all my tasks so I know what's pending.

## Acceptance criteria

### AC1: Tasks displayed in list
**Given:** User has added tasks  
**When:** User views app  
**Then:** 
- All tasks shown in a list
- Each task shows: checkbox, title, delete button
- Most recent task at top (reverse chronological)

### AC2: Empty state shown
**Given:** No tasks exist  
**When:** User views app  
**Then:** 
- Empty state message: "No tasks yet. Add one above!"
- Friendly, encouraging tone
- Not a blank screen

### AC3: Task status visible
**Given:** Tasks exist (some complete, some active)  
**When:** User views list  
**Then:** 
- Completed tasks have checkbox checked
- Completed tasks have strikethrough text
- Completed tasks have reduced opacity

### AC4: List scrollable
**Given:** User has many tasks  
**When:** List exceeds viewport height  
**Then:** 
- List scrolls vertically
- Header/input stays fixed
- Scroll is smooth

### AC5: Tasks persist across refreshes
**Given:** User has added tasks  
**When:** User refreshes page  
**Then:** 
- All tasks still visible
- Order preserved
- Completion status preserved
