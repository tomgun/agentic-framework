# F-0003: Complete tasks

## User story
As a user, I want to mark tasks as complete so I can track my progress.

## Acceptance criteria

### AC1: Checkbox interaction
**Given:** Task exists  
**When:** User clicks checkbox  
**Then:** 
- Task marked as complete
- Checkbox shows checkmark
- Title gets strikethrough
- Opacity reduces to 60%
- Changes persisted

### AC2: Toggle complete/incomplete
**Given:** Task is complete  
**When:** User clicks checkbox again  
**Then:** 
- Task marked as incomplete
- Checkmark removed
- Strikethrough removed
- Opacity returns to 100%

### AC3: Keyboard interaction
**Given:** Task row has focus  
**When:** User presses Space or Enter  
**Then:** 
- Same behavior as clicking checkbox
- Toggle complete/incomplete

### AC4: Visual feedback
**Given:** User toggles task  
**When:** State changes  
**Then:** 
- Smooth animation (200ms transition)
- No jarring visual jump
- Clear indication of new state

### AC5: Screen reader accessible
**Given:** User navigates with screen reader  
**When:** Checkbox is focused  
**Then:** 
- Screen reader announces "Complete task [title]"
- Current state announced (checked/unchecked)
- Proper ARIA labels
