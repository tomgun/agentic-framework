# Generated Reports

These reports are auto-generated by the framework's tools to demonstrate project visibility for a mature, evolved project.

## Available Reports

### 📊 dashboard.txt
**Command:** `bash .agentic/tools/dashboard.sh`

Quick overview of project status, current focus, and next priorities.

### 📈 feature-report.txt
**Command:** `bash .agentic/tools/report.sh`

Summary of feature status across 11 features:
- 6 shipped (v1.0.0, v1.1.0, v1.2.0)
- 2 in_progress (v1.3.0)
- 3 planned (v1.4.0+)

### 🔗 feature-graph.md
**Command:** `python3 .agentic/tools/feature_graph.py`

Mermaid diagram showing feature dependencies (11 features, 7 dependency edges). Paste into GitHub/Markdown viewer to visualize the dependency graph.

### 🏥 health-check.txt
**Command:** `python3 .agentic/tools/doctor.py`

Project health check. For this mature project, should show:
- No template content (all filled in)
- All ADRs documented
- Retrospectives on schedule
- Quality automation in place

### ✅ spec-verification.txt
**Command:** `python3 .agentic/tools/verify.py`

Validates cross-references between specs, ADRs, retrospectives, and research docs. Ensures:
- Feature → ADR links valid
- Retrospective → action item links valid
- Research → ADR links valid

### 🔄 retro-check.txt
**Command:** `bash .agentic/tools/retro_check.sh`

Checks if it's time for a retrospective based on `STACK.md` thresholds:
- Time-based: Every 14 days
- Feature-based: Every 5 features
- Shows days/features since last retro

## How to Regenerate

From the project root:

```bash
# Individual reports
bash .agentic/tools/dashboard.sh
bash .agentic/tools/report.sh
python3 .agentic/tools/feature_graph.py
python3 .agentic/tools/doctor.py
python3 .agentic/tools/verify.py
bash .agentic/tools/retro_check.sh

# Or save to reports/ directory
bash .agentic/tools/dashboard.sh > reports/dashboard.txt
python3 .agentic/tools/feature_graph.py > reports/feature-graph.md
# etc.
```

## Additional Tools (not in reports/)

This project also uses:

- **`bash .agentic/tools/whatchanged.sh`**: Show recent changes by feature
- **`python3 .agentic/tools/deps.py`**: Analyze feature dependencies (blocked features)
- **`bash .agentic/tools/search.sh <query>`**: Search across specs/ADRs/retrospectives
- **`bash .agentic/tools/consistency.sh`**: Check code annotations match specs

## When to Run

- **dashboard.sh**: Daily (quick status)
- **report.sh**: After feature status changes
- **feature_graph.py**: When adding features or dependencies
- **doctor.py**: Weekly or before retrospectives
- **verify.py**: Before commits, in CI
- **retro_check.sh**: Weekly (reminds you to retro)

## Integration with Development

These tools support:
- **Context-efficient AI sessions**: Agent reads dashboard instead of all specs
- **Human onboarding**: New devs run dashboard to understand project
- **Retrospectives**: Doctor + verify identify issues
- **Documentation**: Feature graph visualizes complexity
- **Quality gates**: Verify runs in CI

## Maturity Indicators

Compare these reports to `inited_project/reports/` to see differences between:
- **Simple project**: 3 features, all shipped, basic health check
- **Evolved project**: 11 features, multiple states, retrospective tracking

## Note

These are **demo snapshots** showing tool output at a point in time (v1.2.0 shipped, v1.3.0 in progress). In a real project, regenerate as needed rather than committing reports (unless you want historical snapshots for retrospectives/audits).
