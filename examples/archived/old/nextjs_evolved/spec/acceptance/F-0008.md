# F-0008: Per-page metadata

## Technical Story
As a developer, I want to add per-page metadata so search engines can properly index our app.

## Acceptance criteria

### AC1: Root page has metadata
**Given:** Home page (`app/page.tsx`)  
**When:** Developer reviews code  
**Then:** 
- `generateMetadata()` function exports metadata
- Title: "Task Manager - Simple & Fast"
- Description present
- OpenGraph tags present

### AC2: Dynamic metadata for task views
**Given:** Individual task pages (if added)  
**When:** Page loads  
**Then:** 
- Title includes task title
- Description includes task summary

### AC3: Lighthouse SEO improved
**Given:** Production build  
**When:** Lighthouse CI runs  
**Then:** 
- SEO score ≥95 (up from 88)
- No missing meta tags
- Proper heading structure

### AC4: No hydration errors
**Given:** Metadata added  
**When:** App runs in dev mode  
**Then:** 
- No console errors
- No hydration mismatches
- Metadata renders correctly in `<head>`

## Test coverage
- Unit tests: Metadata generation function ⏳
- E2E tests: Lighthouse CI validates ⏳

## Implementation
- File: `app/page.tsx` (add generateMetadata)
- File: `app/layout.tsx` (root metadata)
