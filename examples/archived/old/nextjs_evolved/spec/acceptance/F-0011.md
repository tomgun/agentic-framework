# F-0011: Dark mode

## User story
As a user, I want dark mode so I can use the app comfortably in low-light environments.

## Acceptance criteria

### AC1: Theme toggle button
**Given:** User views app  
**When:** User looks at header/settings  
**Then:** 
- Theme toggle button visible (sun/moon icon)
- Current theme indicated

### AC2: Toggle switches theme
**Given:** Current theme is light  
**When:** User clicks toggle  
**Then:** 
- Theme switches to dark
- All colors invert appropriately
- Smooth transition animation

### AC3: Respects system preference
**Given:** User's OS is set to dark mode  
**When:** User opens app for first time  
**Then:** 
- App starts in dark mode
- Matches system preference

### AC4: Manual override persists
**Given:** User manually selects light mode (despite OS dark mode)  
**When:** User refreshes page  
**Then:** 
- App remains in light mode (user preference overrides system)
- Choice persisted to localStorage

### AC5: Accessibility maintained
**Given:** Dark mode enabled  
**When:** Lighthouse CI runs  
**Then:** 
- Accessibility score ≥95 (not worse)
- Color contrast meets WCAG AA
- All text readable

### AC6: All components themed
**Given:** Dark mode enabled  
**When:** User navigates app  
**Then:** 
- Task list uses dark background
- Inputs use dark theme
- Buttons use appropriate contrast
- No "light leaks" (components not themed)
