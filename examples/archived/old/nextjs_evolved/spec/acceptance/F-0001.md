# F-0001: Add tasks

## User story
As a user, I want to add tasks so I can track what I need to do.

## Acceptance criteria

### AC1: Task form visible
**Given:** User opens app  
**When:** User looks at top of page  
**Then:** 
- Input field with placeholder "What needs to be done?"
- "Add" button next to input
- Form is prominently placed

### AC2: Add task via button
**Given:** User types "Buy milk" in input  
**When:** User clicks "Add" button  
**Then:** 
- Task appears in list below
- Input clears
- Focus returns to input
- Task is persisted to storage

### AC3: Add task via Enter key
**Given:** User types "Buy milk" in input  
**When:** User presses Enter  
**Then:**  
- Same behavior as clicking "Add"
- (Bug found via E2E test in v1.0.0)

### AC4: Empty task validation
**Given:** Input is empty or whitespace only  
**When:** User tries to add  
**Then:** 
- No task added
- Input shows validation error
- User receives feedback

### AC5: Auto-focus after add
**Given:** User successfully adds task  
**When:** Task is added  
**Then:** Input automatically focused for next task (UX improvement)
