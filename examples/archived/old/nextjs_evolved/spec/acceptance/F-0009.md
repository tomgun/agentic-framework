# F-0009: Virtualization for large lists

## User story
As a user with many tasks (>100), I want the app to stay fast so I can manage my tasks efficiently.

## Acceptance criteria

### AC1: Smooth scrolling with 1000+ tasks
**Given:** User has 1000+ tasks  
**When:** User scrolls task list  
**Then:** 
- Scrolling is smooth (60fps)
- No lag or stuttering
- Tasks render instantly

### AC2: Only visible tasks rendered
**Given:** User has 1000+ tasks  
**When:** Developer inspects DOM  
**Then:** 
- Only ~20-30 TaskRow elements in DOM
- Invisible tasks not rendered
- Virtualization library manages rendering

### AC3: All features still work
**Given:** Virtualized list  
**When:** User interacts with tasks  
**Then:** 
- Complete/uncomplete works
- Delete works
- Filter works
- Keyboard navigation works

### AC4: Performance benchmark met
**Given:** Test suite with 10,000 tasks  
**When:** Benchmark runs  
**Then:** 
- Scroll performance >50fps average
- Initial render <500ms
- Memory usage <100MB

### AC5: Empty state still shown
**Given:** No tasks (or all filtered out)  
**When:** User views list  
**Then:** Empty state message shown (not blank)
