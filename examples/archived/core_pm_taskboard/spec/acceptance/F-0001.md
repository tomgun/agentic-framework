# F-0001: Task CRUD Operations

## User Story
As a user, I can create, read, update, and delete tasks so that I can manage my work.

## Acceptance Criteria

### Create
- [ ] User can click "New Task" button
- [ ] User enters title (required, max 200 chars)
- [ ] User enters description (optional, max 2000 chars)
- [ ] Task appears in "To Do" column
- [ ] Task has unique ID and timestamp
- [ ] Empty title shows validation error

### Read
- [ ] User sees all tasks in their respective columns
- [ ] Each task shows title, description (if present), status
- [ ] Task cards are clickable to view/edit

### Update
- [ ] User can click edit button on any task
- [ ] User can change title and description
- [ ] Changes save immediately (no explicit save button)
- [ ] User can move task between To Do/In Progress/Done
- [ ] Validation prevents empty title

### Delete
- [ ] User can click delete button on any task
- [ ] Confirmation dialog appears ("Delete task?")
- [ ] Confirming removes task immediately
- [ ] Canceling does nothing

## Edge Cases
- Creating task with very long title (truncates at 200 chars)
- Editing task while another tab has it open (last write wins for MVP)
- Deleting task that was just created (no issues expected)
- Rapidly clicking create button (should debounce or disable during creation)

## Performance
- Task creation: <50ms
- Task update: <50ms
- Task deletion: <50ms
- Render 100 tasks: <100ms

## Accessibility
- Keyboard navigation works (Tab, Enter, Escape)
- Screen reader announces task creation/update/deletion
- Focus management: returns to appropriate element after actions

## Out of Scope
- Undo/redo (future)
- Task history/audit log (future)
- Bulk operations (future)
