# Architecture Decision Records (ADRs)

This directory contains ADRs for the **Agentic Framework itself** - decisions about how the framework is built and why.

For ADRs in projects using the framework, see `.agentic/spec/decisions/` (if enabled).

## Purpose

- Document WHY decisions were made, not just what
- Prevent future contributors from undoing intentional decisions
- Provide context for seemingly "redundant" or "suboptimal" choices

## Format

Each ADR follows this structure:
- **Status**: Proposed / Accepted / Deprecated / Superseded
- **Context**: What situation prompted this decision
- **Decision**: What we decided to do
- **Rationale**: Why this approach was chosen
- **Consequences**: What this means going forward
