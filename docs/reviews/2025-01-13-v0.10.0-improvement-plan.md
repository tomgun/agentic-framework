## Phase 1: Tool Consolidation

### Objective
Make `doctor.sh` THE single verification command by having it orchestrate existing tools.

### Current Tool Overlap

```
VERIFICATION CLUSTER (consolidate these):
├── doctor.sh/py         → Keep as primary entry point
├── verify.sh/py         → Merge functionality into doctor
├── consistency.sh/py    → Merge functionality into doctor
├── validate_specs.py    → Merge functionality into doctor
├── validate_formats.py  → Merge functionality into doctor
├── check-untracked.sh   → Merge functionality into doctor
└── project-health.sh    → Merge or deprecate

KEEP AS STANDALONE (distinct purposes):
├── report.sh/py         → User-facing "what needs attention"
├── coverage.sh/py       → Specific purpose (annotations)
└── pre-commit-check.sh  → Git integration point
```

### Implementation Tasks

#### Task 1.1: Enhance doctor.sh

**File**: `.agentic/tools/doctor.sh`

Add modes:
```bash
doctor.sh              # Quick health check (current behavior)
doctor.sh --full       # Run ALL verification checks
doctor.sh --pre-commit # Fast checks suitable for pre-commit
doctor.sh --verbose    # Detailed output for debugging
```

`--full` mode orchestrates:
1. Current doctor.py checks (file presence, format)
2. verify.py checks (spec cross-references)
3. consistency.py checks (spec-code sync)
4. validate_specs.py checks (format validation)
5. check-untracked.sh (git state)
6. wip.sh check (interrupted work)

**Output format**:
```
┌─────────────────────────────────────────────────┐
│           doctor.sh --full                      │
├─────────────────────────────────────────────────┤
│ PROJECT HEALTH                                  │
│ ├─ [✓] Required files present                  │
│ ├─ [✓] No empty/template files                 │
│ └─ [✓] Profile detected: core+product          │
│                                                 │
│ SPEC CONSISTENCY                                │
│ ├─ [✓] Cross-references valid                  │
│ ├─ [✓] Feature status matches state            │
│ └─ [!] 1 shipped feature missing acceptance    │
│                                                 │
│ CODE SYNC                                       │
│ ├─ [✓] Code paths exist                        │
│ └─ [✓] No orphan features                      │
│                                                 │
│ GIT STATE                                       │
│ ├─ [✓] No untracked project files              │
│ └─ [✓] No interrupted work (WIP.md)            │
│                                                 │
│ RESULT: ⚠️ 1 WARNING (fix before shipping)      │
└─────────────────────────────────────────────────┘
```

#### Task 1.2: Add Deprecation Warnings

**Files**: verify.sh, consistency.sh, validate_specs.py, validate_formats.py

Add at script start:
```bash
echo "⚠️  DEPRECATED: This tool is now part of 'doctor.sh --full'"
echo "   Run: bash .agentic/tools/doctor.sh --full"
echo ""
# Continue with original functionality for backwards compatibility
```

#### Task 1.3: Update Pre-Commit Hook

**File**: `.agentic/hooks/pre-commit-check.sh`

Change from:
```bash
# Multiple separate calls
bash .agentic/tools/check-untracked.sh
bash .agentic/tools/verify.sh
# etc.
```

To:
```bash
bash .agentic/tools/doctor.sh --pre-commit
```

## Phase 2: Documentation Consolidation

### Objective
Create a concise QUICK_REFERENCE.md (~100 lines) for daily use, keep detailed docs as backup.

### Current Duplication Map

```
agent_operating_guidelines.md  (1186 lines) - THE source of truth
├── CLAUDE.md duplicates: session protocols, tool references
├── session_start.md duplicates: session protocol steps
├── feature_complete.md duplicates: completion gates
├── before_commit.md duplicates: commit checks
├── copilot-instructions.md: 57% overlap with guidelines
└── Various checklists: repeat same rules
```

### Implementation Tasks

#### Task 2.1: Create QUICK_REFERENCE.md

**File**: `.agentic/agents/shared/QUICK_REFERENCE.md`

Target: ~100 lines, just commands and triggers

```markdown
# Agent Quick Reference

## Session Start
1. `bash .agentic/tools/wip.sh check`
2. Read: CONTEXT_PACK.md → STATUS.md → JOURNAL.md (last 3)
3. Greet user with context summary

## Triggers (STOP and check first!)

| User says... | Do this FIRST |
|--------------|---------------|
| "implement", "build", "add" | Check acceptance criteria exist |
| "commit", "push" | Run `doctor.sh --pre-commit` |
| "done", "complete" | Run `doctor.sh --full` |

## Key Commands

| Action | Command |
|--------|---------|
| Full verification | `bash .agentic/tools/doctor.sh --full` |
| Update feature status | `bash .agentic/tools/feature.sh F-#### status shipped` |
| Log progress | `bash .agentic/tools/journal.sh "topic" "done" "next" "blockers"` |
| Check WIP | `bash .agentic/tools/wip.sh check` |

## Gates (Non-negotiable)

1. **Before feature work**: Acceptance file must exist
2. **Before commit**: `doctor.sh --pre-commit` must pass
3. **Before "done"**: `doctor.sh --full` must pass

## Need details?
- Full guidelines: `.agentic/agents/shared/agent_operating_guidelines.md`
- Principles: `.agentic/PRINCIPLES.md`
- Orchestrator: `.agentic/agents/roles/orchestrator-agent.md`
```

#### Task 2.2: Update CLAUDE.md (Root)

**File**: `/CLAUDE.md`

Restructure to:
1. Point to QUICK_REFERENCE.md for daily use
2. Point to agent_operating_guidelines.md for details
3. Point to orchestrator-agent for feature pipelines
4. Remove duplicated content (session protocols, tool lists)

Target: Reduce from 271 lines to ~100 lines

#### Task 2.3: Refactor Checklists to Reference

**Files**: All `.agentic/checklists/*.md`

Change from: Full duplication of rules
Change to: Brief checklist + reference to guidelines

Example (before):
```markdown

```

```markdown
**Details**: See `agent_operating_guidelines.md` Section: "Proactive Session Start"
```

## Phase 3: Elevate Orchestrator Agent

### Objective
Make orchestrator THE default approach for feature work.

### Current State
- Orchestrator defined in `.agentic/agents/roles/orchestrator-agent.md`
- Not referenced in main instruction files
- Agents follow manual checklists instead

### Implementation Tasks

#### Task 3.1: Update Main Instruction Files

**Files**: CLAUDE.md, agent_operating_guidelines.md, QUICK_REFERENCE.md

Add prominent section:
```markdown
## Feature Work: Use Orchestrator

For implementing features, use the orchestrator agent to coordinate:
- It delegates to specialized agents
- It enforces quality gates
- It ensures nothing is forgotten

See: `.agentic/agents/roles/orchestrator-agent.md`
```

#### Task 3.2: Update Auto-Orchestration

**File**: `.agentic/agents/shared/auto_orchestration.md`

Add orchestrator as the coordination mechanism:
```markdown
When "implement F-####" detected:
1. Orchestrator takes over
2. Delegates to specialized agents
3. Verifies gates at each step
```
