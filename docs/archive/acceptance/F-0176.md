# F-0176: Plan-Aware Code Review — Acceptance Criteria

## Acceptance Criteria

- AC-001: Step 1b in reviewing-code SKILL.md searches `.agentic/journal/plans/` for files matching feature IDs found in the PR/diff
- AC-002: If a plan file is found, it is read and used to compare planned deliverables against actual changes
- AC-003: "Plan Alignment" is added as a review dimension in Step 2 checklist alongside correctness, security, etc.
- AC-004: Review flags three categories: missing deliverables (planned but not in diff), unplanned additions (in diff but not in plan), and deviations (different from what plan specified)
- AC-005: When no plan file is found, the step is skipped silently (no error, no noise)
- AC-006: Review checklist reference file (`review_checklist.md`) includes Plan Alignment section
- AC-007: Both SKILL.md copies are updated (`.claude/skills/` and `.agentic/lib/agents/claude/skills/`)

## Tests

- `tests/validate_framework.sh`: reviewing-code SKILL.md mentions plan alignment, review_checklist.md has plan section

## NFR Compliance

NFRs: none

## Out of Scope

- Automated plan-vs-code structural matching (this is LLM judgment, not tooling)
- Modifying the plan file based on review findings
