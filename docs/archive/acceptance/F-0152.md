# F-0152: Semantic Consistency Analysis — Acceptance Criteria

**Feature**: LLM-powered cross-artifact consistency analysis that catches contradictions, ambiguity, and coverage gaps before implementation starts.

---

## Behavior (what the user needs — technology-agnostic)

Before implementing a feature, the agent runs a semantic analysis across spec artifacts (acceptance criteria, NFRs, related features) to catch contradictions, vague requirements, and missing test coverage. Results are severity-rated and advisory — they warn but don't block. The analysis is skippable for offline/air-gapped development.

---

## Acceptance Criteria

### Core Analysis (P1 — MVP)
**Verify independently**: Run `bash .agentic/tools/spec-analyze.sh F-XXXX` on a feature with known gaps
- [ ] **AC-001**: `spec-analyze.sh` exists and accepts a feature ID argument
- [ ] **AC-002**: Ambiguity detection — flags vague adjectives without metrics ("fast", "scalable", "easy")
- [ ] **AC-003**: AC↔test coverage gaps — identifies ACs with no corresponding test
- [ ] **AC-004**: NFR measurability audit — flags NFRs without quantifiable success criteria
- [ ] **AC-005**: Results are severity-rated (CRITICAL/HIGH/MEDIUM/LOW)

### Integration (P1 — workflow wiring)
**Verify independently**: Run `ag implement F-XXXX` and observe pre-implementation output
- [ ] **AC-006**: `implementing-features` skill runs spec-analyze as advisory step before coding
- [ ] **AC-007**: Analysis is advisory (warn, don't block) — agent proceeds after showing results
- [ ] **AC-008**: Analysis is skippable via `spec_analysis: off` setting in STACK.md

### Extended Checks (P2 — deeper analysis)
**Verify independently**: Run spec-analyze on a multi-feature project
- [ ] **AC-009**: Cross-feature terminology consistency — detects naming drift across spec files
- [ ] **AC-010**: AC contradiction detection — finds ACs that conflict within or across features
- [ ] **AC-011**: Constitution alignment — checks ACs against PRINCIPLES.md constraints

### Edge Cases
- [ ] **AC-012**: Missing or empty acceptance file produces clear error, not crash
- [ ] **AC-013**: Analysis works with both old format (## Tests) and new format (## Verification > ### Tests)
