# F-0164: Tiered Verify Loop — Acceptance Criteria

**Feature**: Multi-tier test execution in the verify loop (`ag auto verify --tier`).
**Status**: shipped

---

## Acceptance Criteria

- [x] **AC-1**: Multi-tier STACK.md parsing — `Test commands:` section with `- Name: \`command\`` entries creates ordered TestTier list, skips placeholders
  - Tests: `test_parses_multi_tier_format`, `test_skips_placeholder_commands`, `test_commands_without_backticks`, `test_stops_parsing_at_next_section`

- [x] **AC-2**: Backward compat — old `Test runner:`/`Test command:` format creates single "unit" tier
  - Tests: `test_backward_compat_old_format`, `test_backward_compat_test_command_field`

- [x] **AC-3**: Backward compat — file-based detection (pytest.ini, package.json, etc.) creates single tier
  - Tests: `test_backward_compat_file_detection`

- [x] **AC-4**: Backward compat — explicit `test_command=` creates single "default" tier ignoring STACK.md
  - Tests: `test_explicit_test_command_creates_single_tier`

- [x] **AC-5**: Tiered execution — tiers run in declared order with per-tier results
  - Tests: `test_runs_tiers_in_order`

- [x] **AC-6**: Fast-fail — tier failure stops subsequent tiers by default
  - Tests: `test_fast_fail_stops_at_failing_tier`

- [x] **AC-7**: `continue_on_failure` — next tier still runs when set
  - Tests: `test_continue_on_failure`

- [x] **AC-8**: Per-tier fix loop — each tier retries up to `max_fix_iterations`
  - Tests: `test_tier_fix_loop`

- [x] **AC-9**: Tier filtering — `--tier e2e` runs only matching tiers (prefix match, case-insensitive)
  - Tests: `test_filter_by_prefix`, `test_filter_by_exact_name`, `test_filter_no_match_falls_back_to_all`, `test_tier_filter_runs_subset`

- [x] **AC-10**: Tier-specific fix prompts — e2e gets "real user behavior" prompt + 8000 char context, unit gets 4000
  - Tests: `test_unit_prompt`, `test_e2e_prompt`, `test_e2e_prompt_larger_context`, `test_unit_prompt_smaller_context`, `test_default_prompt`

- [x] **AC-11**: Playwright output parser — parses "X passed" / "X failed" format
  - Tests: `test_playwright_pass`, `test_playwright_mixed`

- [x] **AC-12**: Cypress output parser — parses "Passing: N" / "Failing: N" format
  - Tests: `test_cypress_pass`, `test_cypress_mixed`

- [x] **AC-13**: E2E tiers get longer timeout — 300s default (vs 120s for unit)
  - Tests: `test_e2e_tiers_get_longer_timeout`

- [x] **AC-14**: task.py compatibility — updated `_run_tests()` call works with new API
  - Tests: existing `test_auto_verify.py` suite passes unchanged (23 tests)
