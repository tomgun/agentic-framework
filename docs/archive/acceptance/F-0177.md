# F-0177: Formal Feature State Machine — Acceptance Criteria

## Must Have

- [ ] **AC-01**: `FeatureState` enum defines exactly 10 states (9 lifecycle + deprecated)
- [ ] **AC-02**: `STATE_ORDER` lists 9 states in sequential order (planned through shipped)
- [ ] **AC-03**: `FORWARD_TRANSITIONS` defines 8 sequential forward transitions
- [ ] **AC-04**: `REGRESSION_TRANSITIONS` defines backward transitions per ADR-001 Section 5
- [ ] **AC-05**: `SKIP_TRANSITIONS` allow legacy flows (planned→implementing, planned→shipped, implementing→shipped)
- [ ] **AC-06**: Any state can transition to `deprecated`
- [ ] **AC-07**: `resolve_state()` handles backward-compat aliases (`in_progress` → `implementing`)
- [ ] **AC-08**: `get_current_state()` reads status from FEATURES.md (heading format with `**Status**: value`)
- [ ] **AC-09**: Advisory mode (default): invalid transitions produce WARNING but proceed
- [ ] **AC-10**: Enforce mode: invalid transitions are blocked with error messages
- [ ] **AC-11**: `transition()` updates FEATURES.md via `feature.sh` for consistency
- [ ] **AC-12**: `cascade_invalidations()` returns states invalidated by regression transitions
- [ ] **AC-13**: `get_unblocked()` returns features with available forward transitions, skipping shipped/deprecated
- [ ] **AC-14**: Gate functions check filesystem preconditions (AC file exists, tests reference feature, etc.)
- [ ] **AC-15**: `register_default_gates()` registers all 8 gate functions on the state machine
- [ ] **AC-16**: CLI supports `--status`, `--next`, `--unblocked`, `--dry-run`, `--enforce`
- [ ] **AC-17**: `ag transition` command wired in ag.sh dispatcher

## Should Have

- [ ] **AC-18**: Dry-run mode shows what would happen without modifying state
- [ ] **AC-19**: Gates for early transitions (planned→specced, specced→criteria_set) are hard blocks; later gates are advisory
- [ ] **AC-20**: `GateResult` supports merge for combining multiple gate checks

## Tests

- `tests/test_state_machine.py` — 42 tests covering enum, transitions, regressions, cascades, advisory/enforce, dry-run, queries
- `tests/test_gates.py` — 23 tests covering all 8 gates and registration
