# NFR-0003: Small Batch Work — Acceptance Criteria

## Acceptance Criteria

- AC-001: Memory-seed "TOO BIG" rule triggers when user describes work touching >10 files, breaking into 3-5 smaller tasks
- AC-002: `ag plan` encourages decomposition into batches that fit within reasoning context
- AC-003: Default thresholds are profile-aware: Discovery=15, Formal=10
- AC-004: Pre-commit hook warns (advisory) when staged file count exceeds threshold — safety net, not primary enforcement
- AC-005: Threshold is configurable via `ag set max_files_per_commit <N>`

## Tests

- `tests/validate_framework.sh`: batch size checks
- `pre-commit-check.sh`: advisory file count warning
- LLM test `007_small_batch.sh`: agent awareness of batch limits

## NFR Compliance

This IS an NFR — self-referential compliance not applicable.

## Out of Scope

- Blocking on line count (handled by `max_added_lines` setting separately)
- Splitting already-done work (the point is to plan small, not enforce after the fact)
