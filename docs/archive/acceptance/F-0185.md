# F-0185: Coordination Server for Agent Coordination

**ADR**: ADR-001, Phase 6, Section 4
**Dependencies**: F-0177, F-0180, F-0184

## Acceptance Criteria

- [x] **AC-001**: 8 coordination tools: `claim_feature`, `release_feature`, `transition_state`, `get_unblocked`, `poll_changes`, `report_status`, `request_review`, `submit_review`
- [x] **AC-002**: Tools delegate to existing Python classes where possible; `claim_feature`/`release_feature` are new logic in agents_helpers.py
- [x] **AC-003**: `ag coord start | stop | status` commands manage the coordination server process
- [x] **AC-004**: Graceful degradation: without server, framework uses file-based coordination (already the case)
- [x] **AC-005**: Coexists with control.py Unix socket (different concerns)
- [x] **AC-006**: Files remain authoritative — no in-memory cache, read files on every request
- [x] **AC-007**: Unit tests for tools (pure function tests) + 2-3 integration tests for HTTP transport
