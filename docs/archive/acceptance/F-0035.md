# F-0035: Agent Role Definitions - Acceptance Criteria

## AC-001: Role Files Exist

**Given** an initialized agentic project  
**When** checking `.agentic/agents/roles/`  
**Then** 9 role definition files exist:
- `orchestrator-agent.md` (manager/puppeteer)
- `research_agent.md`
- `planning_agent.md`
- `test_agent.md`
- `implementation_agent.md`
- `review_agent.md`
- `spec_update_agent.md`
- `documentation_agent.md`
- `git_agent.md`

## AC-002: Role Structure

**Given** any agent role file  
**When** reading its contents  
**Then** it contains:
- Role name and purpose
- "Context to Read" section
- "Responsibilities" section
- "Output" section (what this agent creates)
- "What You DON'T Do" section (clear boundaries)
- "Handoff" section (how to pass to next agent)

## AC-003: No Role Overlap

**Given** all 8 role definitions  
**When** comparing responsibilities  
**Then** each role has unique, non-overlapping responsibilities:
- Only Test Agent writes tests
- Only Implementation Agent writes production code
- Only Git Agent commits code
- Only Spec Update Agent updates FEATURES.md status

## AC-004: Handoff Chain

**Given** the role definitions  
**When** following handoff instructions  
**Then** a complete chain exists:
- Research → Planning → Test → Implementation → Review → Spec Update → Documentation → Git

## Verification

- [ ] AC-001: 9 role files exist in `.agentic/agents/roles/` (including orchestrator)
- [ ] AC-002: Each role has required sections
- [ ] AC-003: Responsibilities don't overlap
- [ ] AC-004: Handoff chain is complete
