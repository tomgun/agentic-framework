# F-0119: Feature Change Manifest Generation

## Acceptance Criteria

- [x] `manifest.sh F-XXXX` generates manifest from feature ID (searches commits)
- [x] `manifest.sh --branch feature/foo` generates from branch
- [x] `manifest.sh --since 2026-02-01` generates from date range
- [x] `manifest.sh --commits abc123,def456` generates from explicit commits
- [x] `manifest.sh F-XXXX --migration 116` embeds into migration file
- [x] Outputs to `.agentic-journal/manifests/` directory
- [x] Generates JSON format with commits, files, stats
- [x] Groups files by type (code, tests, docs, config)

## Test Commands

```bash
# Generate manifest for a feature
bash .agentic/tools/manifest.sh F-0116

# Generate from branch
bash .agentic/tools/manifest.sh --branch main

# Generate from date
bash .agentic/tools/manifest.sh --since 2026-02-01
```
