# F-0098: Generate Claude Skills from Subagents

## Summary
Generate Claude Code Skills (`.claude/skills/`) from subagent definitions (`.agentic/agents/claude/subagents/`), enabling auto-discovery of capabilities while maintaining a single source of truth.

## Acceptance Criteria

### AC1: generate-skills.sh creates Skills from subagents
- [x] Script reads all `.agentic/agents/claude/subagents/*.md` files
- [x] Creates `.claude/skills/<name>/SKILL.md` for each subagent
- [x] Generated Skills include frontmatter with `description` (for auto-discovery)
- [x] Generated Skills include `model` recommendation (haiku/sonnet/opus)
- [x] Generated Skills include `allowed-tools` where appropriate
- [x] Generated Skills contain a note pointing to source file
- [x] Running script twice produces identical output (idempotent)

### AC2: install.sh generates Skills automatically
- [x] Skills are generated during `install.sh` execution
- [x] Works for both new installs and upgrades
- [x] Handles case where `.claude/` directory doesn't exist

### AC3: install.sh offers to suggest project-specific agents
- [x] After install, asks user if they want agent suggestions
- [x] If yes, runs `suggest-agents.sh`
- [x] Shows detected tech stack and recommended agents
- [ ] User can choose to create suggested agents (manual step)

### AC4: upgrade.sh regenerates Skills
- [x] Skills are regenerated during upgrade
- [x] Old generated skills are replaced (not duplicated)
- [x] Custom (non-generated) skills in `.claude/skills/` are preserved

### AC5: Generated Skills work in Claude Code
- [ ] Skills are auto-discovered based on task description (manual test needed)
- [ ] Model recommendation is respected (manual test needed)
- [ ] Tool restrictions are applied (manual test needed)

## Out of Scope
- Generating skills for other tools (Cursor, Copilot) - different formats
- Custom skill creation wizard - use `create-agent.sh` then regenerate
