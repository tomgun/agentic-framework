# F-0122: Multi-Tool LLM Testing Infrastructure

**Feature**: Multi-Tool LLM Testing Infrastructure
**Status**: ACCEPTED
**Accepted by**: Cursor Agent
**Accepted at**: 2026-02-05

## Description

Enable running LLM behavioral tests across different AI tools (Claude CLI, Codex CLI, Cursor CLI, Cursor IDE, Copilot IDE). This includes environment detection, interactive test mode for IDE-based agents, machine-readable test definitions, and an `ag test llm` command.

## Acceptance Criteria

### Test Definitions
- [x] `tests/llm/test_definitions.json` exists with machine-readable test specs
- [x] JSON includes all critical tests (001, 002, 003, 005)
- [x] Each test has: id, description, category, profile, prompt, expected outcomes

### Interactive Runner
- [x] `tests/llm/interactive_runner.py` exists and is executable
- [x] `--list` shows available tests with descriptions
- [x] `--critical` filters to critical tests only
- [x] `--setup TEST_ID` creates test project with proper setup
- [x] `--verify TEST_ID` verifies test outcomes
- [x] Supports `--output` for verifying agent response text

### ag.sh Integration
- [x] `ag test llm` command exists in ag.sh
- [x] Environment detection works (claude, codex, cursor-ide, copilot-ide)
- [x] `ag test llm --list` lists tests
- [x] `ag test llm --critical` shows/runs critical tests
- [x] `ag test llm --setup` sets up individual tests
- [x] `ag test llm --verify` verifies test outcomes
- [x] `ag test llm --detect` shows detected environment

### CLI Tool Support

- [x] Codex CLI: Fully automated via harness.sh
- [x] Cursor CLI: Support added (TOOL=cursor-cli)
- [x] Cursor IDE: Interactive mode via interactive_runner.py

### Test Execution

- [x] Results documented in tests/VERIFICATION_REPORT.md

## Verification

```bash
# List tests
python3 tests/llm/interactive_runner.py --list

# Environment detection
bash .agentic/tools/ag.sh test llm --detect

# Run individual test setup/verify
python3 tests/llm/interactive_runner.py --setup 001
python3 tests/llm/interactive_runner.py --verify 001 --output "agent response..."
```

## Notes

- Interactive mode is required for IDE-based tools (Cursor, Copilot) that don't have CLIs
- The agent running inside the IDE executes tests by responding to prompts
- Cursor CLI (cursor-agent) support added for future automated testing when available
