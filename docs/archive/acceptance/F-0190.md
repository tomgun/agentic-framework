# F-0190: Backlog/Roadmap — Structural Work Assignment

Git-tracked ordered work queue that tells any agent on any machine what to work on next.

## Acceptance Criteria

### P1: Core backlog operations

- [x] **AC-01**: `backlog.sh add F-XXXX` creates BACKLOG.json with item at end of queue; validates feature exists in FEATURES.md
- [x] **AC-02**: `backlog.sh add F-XXXX --position 0` places item at top of queue; sets `became_current_at`
- [x] **AC-03**: `backlog.sh add --task "description"` adds non-feature task item
- [x] **AC-04**: `backlog.sh current` prints position 0 item; exits 1 if backlog is empty
- [x] **AC-05**: `backlog.sh next` prints position 1 item
- [x] **AC-06**: `backlog.sh done` removes position 0; sets `became_current_at` on new position 0
- [x] **AC-07**: `backlog.sh list` prints full backlog with positions and dependency info
- [x] **AC-08**: `backlog.sh remove F-XXXX` removes specific item by ID
- [x] **AC-09**: `backlog.sh move F-XXXX N` moves item to position N
- [x] **AC-10**: `backlog.sh clear` empties the backlog
- [x] **AC-11**: Auto-discovers plan file and acceptance criteria as refs when adding feature items

### P1: Structural gates

- [x] **AC-12**: `ag start` shows current backlog item prominently with notes, refs, and next item
- [x] **AC-13**: `ag implement F-XXXX` auto-adds F-XXXX to backlog at position 0 if not present
- [x] **AC-14**: `ag implement F-XXXX` where F-XXXX != position 0 exits with BLOCKED (exit 1)
- [x] **AC-15**: `ag implement F-XXXX` where F-XXXX == position 0 proceeds normally
- [x] **AC-16**: `ag work "desc"` with feature items in backlog AND feature_tracking=yes exits BLOCKED
- [x] **AC-17**: `ag done F-XXXX` auto-advances backlog (removes position 0, sets `became_current_at` on next)
- [x] **AC-18**: `SKIP_BACKLOG=1 ag implement F-XXXX` bypasses backlog gate with warning

### P2: Integration

- [x] **AC-19**: `ag plan F-YYYY` shows advisory warning if F-YYYY != position 0
- [x] **AC-20**: `ag spec F-YYYY` shows advisory warning if F-YYYY != position 0
- [x] **AC-21**: `ag backlog` top-level command works with all subcommands (list, add, done, move, remove, clear)
- [x] **AC-22**: Staleness detection: `ag start` warns if current item's `became_current_at` > 7 days old
- [x] **AC-23**: Dependency tracking: items can declare `depends_on` array; advisory warning shown at implement time
- [x] **AC-24**: Empty backlog or no BACKLOG.json: all commands work normally with no constraints
- [x] **AC-25**: `backlog.sh done` when next item has unmet deps skips to first unblocked or warns
- [x] **AC-26**: `ag implement F-XXXX` where F-XXXX is `shipped`/`deprecated` shows lifecycle warning
- [x] **AC-27**: `crunch.py._read_planned_features()` uses backlog order when BACKLOG.json exists
- [x] **AC-28**: `BACKLOG_FILE` path defined in both `paths.sh` and `paths.py`
