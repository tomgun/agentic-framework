# F-0157: Directory Restructure & Tarball Distribution — Acceptance Criteria

**Feature**: Restructure `.agentic/` to separate framework runtime from project state with tarball distribution.

---

## Acceptance Criteria

### P1 — Structure

- [x] **AC-001**: Framework runtime dirs (tools, agents, workflows, quality, checklists, init, hooks, claude-hooks, prompts, schemas, presets, support, token_efficiency, quality_profiles) exist under `.agentic/lib/`
- [x] **AC-002**: `lib/templates/` contains spec templates (renamed from `spec/` inside lib to avoid confusion)
- [x] **AC-003**: Tracking files (STATUS.md, TODO.md, HUMAN_NEEDED.md, CONTRIBUTIONS.md, OVERVIEW.md) live at `.agentic/` root
- [x] **AC-004**: `.agentic/journal/` replaces `.agentic-journal/`
- [x] **AC-005**: `.agentic/spec/` replaces root `spec/`
- [x] **AC-006**: `.agentic/session/` replaces `.agentic-state/`
- [x] **AC-007**: `.agentic/local/` replaces `.agentic-local/`
- [x] **AC-008**: Project root has only convention/tool-required files (CLAUDE.md, CODEX.md, README.md, AGENTS.md, STACK.md, CONTEXT_PACK.md, .cursorrules)

### P1 — Distribution

- [x] **AC-009**: `.github/workflows/release.yml` builds `agentic-lib-v{VERSION}.tar.gz` on tag push
- [x] **AC-010**: `install.sh` copies thin wrappers + builds/copies tarball + extracts lib + updates .gitignore
- [x] **AC-011**: `remote-install.sh` downloads lib tarball from GitHub release assets
- [x] **AC-012**: User project .gitignore includes `.agentic/lib/` and `.agentic/session/`
- [x] **AC-013**: User projects commit only thin wrappers + tarball (not 369 lib files)

### P1 — Backward Compatibility

- [x] **AC-014**: All constitution files (CLAUDE.md, .cursorrules, CODEX.md, copilot-instructions.md, codex instructions) updated with new paths
- [x] **AC-015**: All `.claude/skills/` reference correct new paths
- [x] **AC-016**: `ag` commands work via thin wrapper → bootstrap → lib/tools/ag.sh
