# F-0171: Spec Verification Tool — Acceptance Criteria

## Acceptance Criteria

- AC-001: `spec-audit.sh` exists and runs without error on shipped features
- AC-002: Structural layer: checks acceptance file exists with required sections
- AC-003: Coverage layer: checks acceptance criteria are defined (not empty)
- AC-004: Test heuristics layer: detects empty test bodies and zero assertions
- AC-005: LLM review: `test-review-prompt.md` template exists for intent-match review
- AC-006: `spec-audit.sh --since-last` scopes to features changed since last audit
- AC-007: `spec-audit.sh --report` generates markdown report in `docs/retrospectives/`
- AC-008: `ag audit` command routes to spec-audit.sh
- AC-009: Verification results written to `.qa-tracker.json`

## Tests

- `tests/validate_framework.sh`: spec-audit.sh exists and is executable, test-review-prompt.md exists, ag.sh has audit command

## NFR Compliance

NFRs: none

## Out of Scope

- Automatic test fixing (advisory only)
- CI integration (manual/retro trigger only)
