# F-0064: Script Help Messages - Acceptance Criteria

**Feature**: All scripts have clear --help / usage messages

**Version**: 0.3.0

---

## Acceptance Criteria

### Help Available

- [x] **AC-001**: Major scripts respond to `--help` or show usage on error
- [x] **AC-002**: Help message explains what the script does
- [x] **AC-003**: Help message shows usage syntax
- [x] **AC-004**: Help message includes examples

### Scripts Covered

- [x] **AC-010**: `wip.sh` has help message
- [x] **AC-011**: `feature.sh` has help message
- [x] **AC-012**: `journal.sh` has help message
- [x] **AC-013**: `status.sh` has help message
- [x] **AC-014**: `blocker.sh` has help message

### Quality

- [x] **AC-020**: Help is concise (not overwhelming)
- [x] **AC-021**: Examples use realistic values
- [x] **AC-022**: Exit codes documented where relevant

## Test Scenarios

### Scenario 1: New User Explores Script

**Given**: Developer finds wip.sh
**When**: They run `bash wip.sh --help`
**Then**: They see what it does, how to use it, examples

### Scenario 2: Wrong Arguments

**Given**: Developer runs script with wrong arguments
**When**: Script detects invalid input
**Then**: Script shows usage message (not cryptic error)

### Scenario 3: Copy-Paste Examples

**Given**: Developer reads help message
**When**: They copy an example command
**Then**: The command works (examples are valid)
