# F-0195: Multi-Session Collision Prevention

## Acceptance Criteria

### AC-1: Session auto-registration
- [ ] `session-register` creates entry in AGENTS.json with type="session", pid, worktree
- [ ] `session-deregister` removes the entry matching worktree + pid
- [ ] Duplicate registration (same worktree+pid) updates existing entry, not creates new
- [ ] SessionStart.sh calls session-register with $PPID

### AC-2: Count-others collision detection
- [ ] `count-others` returns 0 when only self is registered
- [ ] `count-others` returns 1+ when other sessions/entries exist on same worktree
- [ ] `count-others` excludes self by PID match
- [ ] `count-others` counts all entry types (session + feature), not just sessions

### AC-3: Stale cleanup
- [ ] `cleanup-stale` removes session entries where PID is dead
- [ ] `cleanup-stale` removes session entries where heartbeat > 30 minutes old (PID recycling guard)
- [ ] `cleanup-stale` uses OR logic: PID dead OR heartbeat expired
- [ ] `cleanup-stale` does NOT remove non-session entries (feature entries)
- [ ] SessionStart.sh runs cleanup-stale before registration

### AC-4: Heartbeat
- [ ] `session-heartbeat` updates last_checkpoint timestamp
- [ ] UserPromptSubmit.sh calls session-heartbeat on every prompt

### AC-5: Hook integration
- [ ] SessionStart.sh: registers session, warns if others active
- [ ] Stop.sh: deregisters session
- [ ] UserPromptSubmit.sh: injects advisory collision warning when others active
- [ ] All hooks use $PPID (stable via exec bash wrappers), not $$
- [ ] All hooks fail gracefully (2>/dev/null || true) — never block session

### AC-6: Instruction hardening
- [ ] Claude CLAUDE.md template contains count-others collision rule
- [ ] Root CLAUDE.md contains count-others collision rule
- [ ] cursorrules.txt contains behavioral collision rule (no tool ref)
- [ ] copilot-instructions.md contains behavioral collision rule (no tool ref)
- [ ] codex-instructions.md contains behavioral collision rule (no tool ref)
- [ ] memory-seed.md contains collision guard rule
- [ ] agent_operating_guidelines.md has collision guard in gates table

### AC-7: Tests pass
- [ ] Unit tests for session-register/deregister/count-others/cleanup-stale/heartbeat
- [ ] validate_framework.sh passes
