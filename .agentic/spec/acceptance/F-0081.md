# F-0081: Orchestrator Agent - Acceptance Criteria

## AC-001: Orchestrator Role File Exists

**Given** an initialized agentic project  
**When** checking `.agentic/agents/roles/`  
**Then** `orchestrator-agent.md` exists with:
- Core responsibilities section
- Available agents to delegate to (table)
- Feature pipeline workflow
- Compliance checks section
- Anti-patterns section

## AC-002: Delegation Not Implementation

**Given** the orchestrator agent definition  
**When** reading its responsibilities  
**Then** it clearly states:
- "Delegate to specialized agents (never implements itself)"
- "NEVER write code yourself"
- References to @implementation-agent, @test-agent, etc.

## AC-003: Compliance Verification

**Given** the orchestrator agent definition  
**When** reading the compliance checks section  
**Then** it includes verification for:
- Acceptance criteria exist (spec/acceptance/F-####.md)
- Tests exist and pass
- FEATURES.md updated
- No untracked files
- pre-commit-check.sh passes

## AC-004: Cursor Integration

**Given** the framework with cursor-agents set up  
**When** checking `.cursor/agents/`  
**Then** `orchestrator-agent.md` exists with:
- @agent-name syntax for delegation
- Compliance checklist
- Usage example

## AC-005: Pipeline Management

**Given** the orchestrator agent definition  
**When** reading the pipeline section  
**Then** it describes:
- 8-step pipeline (Research → Git)
- Verification at each step
- Pipeline status tracking file format
