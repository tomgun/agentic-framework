# F-009: Pre-Commit Quality Gates - Acceptance Criteria

**Feature**: Blocking validation before commits

**Version**: 0.6.0

---

## Acceptance Criteria

### Script Exists

- [x] **AC-001**: `pre-commit-check.sh` exists in `.agentic/hooks/`
- [x] **AC-002**: Script is executable
- [x] **AC-003**: Script returns exit code 0 on success, 1 on failure

### WIP Check

- [x] **AC-010**: Script checks if .agentic/WIP.md exists
- [x] **AC-011**: If .agentic/WIP.md exists, commit is BLOCKED
- [x] **AC-012**: Clear message explains WIP must be completed first

### Acceptance Criteria Check

- [x] **AC-020**: Script checks shipped features have acceptance files
- [x] **AC-021**: Missing acceptance file = BLOCKED
- [x] **AC-022**: Script identifies which features are missing criteria

### Batch Size Check

- [x] **AC-030**: Script counts staged files
- [x] **AC-031**: >10 files = Note (moderate batch)
- [x] **AC-032**: >15 files = Warning (too large)
- [x] **AC-033**: Warning is advisory (does not block)

### STACK.md Validation

- [x] **AC-040**: Script checks version consistency where detectable
- [x] **AC-041**: Mismatched versions = Warning (advisory)

---

## Validation Commands

```bash
# Run pre-commit check
bash .agentic/hooks/pre-commit-check.sh

# Test WIP blocking
touch .agentic/WIP.md
bash .agentic/hooks/pre-commit-check.sh  # Should fail
rm .agentic/WIP.md

# Test batch size warning
for i in {1..15}; do git add "file$i.txt" 2>/dev/null; done
bash .agentic/hooks/pre-commit-check.sh  # Should warn
```

## Test Scenarios

### Scenario 1: All Checks Pass

**Given**: No WIP, all features have acceptance, <10 files
**When**: Run pre-commit check
**Then**: Exit code 0, "ALL QUALITY GATES PASSED"

### Scenario 2: WIP Blocks Commit

**Given**: .agentic/WIP.md exists
**When**: Run pre-commit check
**Then**: Exit code 1, "BLOCKED: .agentic/WIP.md exists"

### Scenario 3: Missing Acceptance Criteria

**Given**: Feature F-0005 shipped but no spec/acceptance/F-0005.md
**When**: Run pre-commit check
**Then**: Exit code 1, "BLOCKED: Shipped features missing acceptance"

### Scenario 4: Large Batch Warning

**Given**: 20 files staged
**When**: Run pre-commit check
**Then**: Warning shown, but commit not blocked (exit 0)
