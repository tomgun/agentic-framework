# F-0221: ag.sh Decomposition - Acceptance Criteria

**Feature**: Break the monolithic ag.sh (4,325 lines, 58 functions) into sourced modules while preserving all behavior. ag.sh becomes a thin dispatcher that sources command modules.

---

## Behavior (what the user needs — technology-agnostic)

All `ag` commands continue to work identically. No user-facing changes. The file becomes maintainable: each command group lives in its own module, sourced by the dispatcher. New commands are added to modules, not to a 4000+ line file.

---

- [ ] **AC-014**: Module files live at `.agentic/lib/tools/commands/` directory
- [ ] **AC-015**: All existing `ag` commands produce identical output before and after decomposition (behavioral equivalence)
