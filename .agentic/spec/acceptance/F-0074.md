## Test Scenarios

### Scenario 1: Algorithm Choice

**Given**: Agent implementing search functionality
**When**: Agent follows green coding principles
**Then**: Agent chooses O(log n) over O(n) where appropriate

### Scenario 2: Caching Decision

**Given**: Agent considering caching for performance
**When**: Agent reads green_coding.md
**Then**: Agent understands benefits AND risks (invalidation complexity)

### Scenario 3: Event-Driven Design

**Given**: Agent implementing real-time updates
**When**: Agent follows green principles
**Then**: Agent uses webhooks/events, not polling intervals

### Scenario 4: Safety First

**Given**: Agent optimizing code
**When**: Optimization would add significant complexity
**Then**: Agent prioritizes correctness over micro-optimization
