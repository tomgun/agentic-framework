# F-0226: Post-Merge Dogfooding

## Acceptance Criteria

### Core Detection Script (P1 — MVP)

- [ ] **AC-001**: `dogfood-sync.sh` Phase 1 delegates to `instruction-sync.sh --quiet` and synthesizes a one-line summary of ag command parity across instruction files
- [ ] **AC-002**: `dogfood-sync.sh` Phase 2 uses per-file sentinel lists to detect when sentinel strings present in a template are absent from the corresponding root file; uses full-check mode for CLAUDE.md/copilot/codex and reduced-check mode (Quick Commands + trigger table only) for .cursorrules
- [ ] **AC-003**: `dogfood-sync.sh` Phase 3 delegates to `memory-check.sh --quiet` and synthesizes a one-line summary of memory-seed freshness
- [ ] **AC-004**: Each drift item includes an actionable fix suggestion (template line number + where to add in root)

### Suppression (P1 — MVP)

- [ ] **AC-005**: Root files can suppress false positives with `<!-- dogfood:ignore: SENTINEL -->` comments; suppressed sentinels are not reported as drift

### Integration (P1 — MVP)

- [ ] **AC-006**: `ag done` on main automatically runs `dogfood-sync.sh --brief` when `FRAMEWORK_DEVELOPMENT.md` exists in project root
- [ ] **AC-007**: `ag done` on main skips dogfood sync when `FRAMEWORK_DEVELOPMENT.md` does not exist (user projects unaffected)
- [ ] **AC-008**: Drift is reported as advisory — does not block `ag done` (uses `|| true`)

### Standalone Command (P2 — Enhancement)

- [ ] **AC-009**: `ag dogfood` subcommand runs full report with fix suggestions; `ag dogfood --brief` runs one-line-per-phase summary

### NFR Constraints (P1 — required)

- [ ] **AC-010**: Instruction files updated with `ag dogfood` in quick commands (CLAUDE.md, cursorrules, copilot, codex templates + auto_orchestration + memory-seed) — per NFR-0003 small batch and NFR-0004 spec-first

## Tests

- **Automated**: `bash tests/test_dogfood_sync.sh` — 7 test cases with mock fixtures:
  - Clean state (all sentinels present) → exit 0
  - Missing sentinel → exit 1, reports drift with fix suggestion
  - Suppressed sentinel → exit 0
  - Reduced mode (.cursorrules) → only Quick Commands checked
  - Phase 1 delegation (instruction-sync.sh called)
  - Phase 3 delegation (memory-check.sh called)
  - `--brief` output format (one line per phase)
- **Automated**: `bash tests/validate_framework.sh` (framework validation)

## Verification

- **Manual**: Run `ag dogfood` in framework repo, verify drift report for known divergence
- **Manual**: Run `ag done` on main, verify dogfood sync phase appears after VERSION bump
