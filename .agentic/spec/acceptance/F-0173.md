# F-0173: QA Tracker State Machine — Acceptance Criteria

## Acceptance Criteria

- AC-001: `qa-tracker.sh` manages `.agentic/session/.qa-tracker.json` state
- AC-002: `qa-tracker.sh status` returns one-liner for dashboards
- AC-003: `qa-tracker.sh pending` lists open propagation items
- AC-004: `qa-tracker.sh add-propagation` creates new propagation entries with PQ-XXX IDs
- AC-005: `qa-tracker.sh resolve PQ-XXX` marks items resolved
- AC-006: `qa-tracker.sh defer PQ-XXX "reason"` defers with documented reason
- AC-007: `qa-tracker.sh check-escalation` applies time-based escalation (warn/escalate)
- AC-008: `periodic-checks.sh` calls `check_qa_health()` for escalation
- AC-009: Pre-commit hook shows advisory warning when propagation items exist
- AC-010: Session start checklist includes QA tracker status
- AC-011: `profiles.conf` includes qa_propagation_warn_days, qa_propagation_escalate_days, qa_audit_freshness_days
- AC-012: STACK template includes new QA settings
- AC-013: `migration.sh create` auto-creates propagation items via `qa-tracker.sh`
- AC-014: `nfr.sh` status update auto-creates propagation items via `qa-tracker.sh`

## Tests

- `tests/validate_framework.sh`: qa-tracker.sh exists and is executable, profiles.conf has QA settings

## NFR Compliance

NFRs: none

## Out of Scope

- Blocking pre-commit on propagation items (advisory only)
