# F-0097: Worktree Management Tool - Acceptance Criteria

**Feature**: Tool to manage git worktrees for parallel agent development

**Status**: Accepted

---

## AC-001: worktree.sh exists and is executable

**Given**: The framework is installed
**When**: User looks for the worktree tool
**Then**: `.agentic/tools/worktree.sh` exists and is executable

**Verification**:
```bash
[[ -x .agentic/tools/worktree.sh ]] && echo "PASS" || echo "FAIL"
```

---

## AC-002: Create command creates worktree and branch

**Given**: A git repository
**When**: User runs `worktree.sh create F-001 "Description"`
**Then**:
- Worktree is created at `../repo-f-0001/`
- Branch `feature/F-001` is created
- Agent is registered in `.agentic/AGENTS_ACTIVE.md`

**Verification**:
```bash
grep -q "git worktree add" .agentic/tools/worktree.sh && echo "PASS" || echo "FAIL"
```

---

## AC-003: List command shows worktrees and agents

**Given**: One or more worktrees exist
**When**: User runs `worktree.sh list`
**Then**: Both git worktrees and AGENTS_ACTIVE.md entries are shown

**Verification**:
```bash
grep -q "git worktree list" .agentic/tools/worktree.sh && echo "PASS" || echo "FAIL"
```

---

## AC-004: Remove command cleans up worktree

**Given**: A worktree exists for feature F-001
**When**: User runs `worktree.sh remove F-001`
**Then**:
- Worktree is removed
- Agent entry is removed from AGENTS_ACTIVE.md
- User is prompted about branch deletion

**Verification**:
```bash
grep -q "git worktree remove" .agentic/tools/worktree.sh && echo "PASS" || echo "FAIL"
```

---

## AC-005: Help command shows usage

**Given**: The tool is installed
**When**: User runs `worktree.sh help`
**Then**: Usage instructions are displayed

**Verification**:
```bash
bash .agentic/tools/worktree.sh help | grep -q "USAGE" && echo "PASS" || echo "FAIL"
```
