# F-0004: Feature Tracking & Status

## Acceptance Criteria

- [ ] AC1: FEATURES.md template has status field for each feature
- [ ] AC2: Valid statuses: proposed, in_progress, shipped, deprecated
- [ ] AC3: feature.sh script can update feature status
- [ ] AC4: feature.sh can update impl-state (none, partial, complete)
- [ ] AC5: feature.sh can update tests status (none, partial, complete)
- [ ] AC6: feature.sh can mark feature as accepted (yes/no)
- [ ] AC7: Validation script checks for invalid status values

## Verification

- **Automated**:
  - feature.sh exists and is executable
  - feature.sh updates FEATURES.md correctly
  - validate_specs.py checks status values
- **Manual**: Agent uses feature.sh during development
- **Profile**: Formal only
