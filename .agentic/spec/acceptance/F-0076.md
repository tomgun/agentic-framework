## Test Scenarios

### Scenario 1: Incremental Feature

**Given**: Large feature F-0020 "User authentication"
**When**: Agent breaks into phases: 1) Login form, 2) API integration, 3) Session management
**Then**: Each phase is shipped separately, all working

### Scenario 2: Learning Through Building

**Given**: Initial spec: "User can upload images"
**When**: Implementing, agent discovers: need size limits, format validation, virus scanning
**Then**: Spec updated with discoveries, next iteration includes these

### Scenario 3: Small Validated Steps

**Given**: Agent working on feature
**When**: Following iterative approach
**Then**: Pick task → implement → test → verify → ship → next task

### Scenario 4: Complementary with Small Batch

**Given**: Both principles active
**When**: Agent works
**Then**: Small Batch = HOW (one feature, <10 files), Iterative = PHILOSOPHY (ship, learn, adapt)
