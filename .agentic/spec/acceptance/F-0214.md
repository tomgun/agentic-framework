# F-0214: Parallel Epic Execution with Worktrees — Acceptance Criteria

## AC-001: Parallel spawning
`ag auto epic F-XXXX --parallel` spawns N concurrent Claude processes in separate worktrees.

## AC-002: Rolling slot management
Completed slots immediately filled from pending queue (not batch-based).

## AC-003: Atomic AGENTS.json
Claims/releases use fcntl locking via existing agents_helpers.py.

## AC-004: Signal cleanup
Ctrl+C kills all active processes, cleans up all worktrees.

## AC-005: Max parallel flag
`--max-parallel N` limits concurrent processes (default from `max_parallel_agents` setting).

## AC-006: Timeout flag
`--timeout N` kills features exceeding time limit (default 600s).

## AC-007: Per-feature logs
Per-feature logs captured to `.agentic/session/parallel-logs/{F-XXXX}.log`.

## AC-008: Compatible result shape
SchedulerResult returned with same shape as sequential (no downstream breakage).

## AC-009: Integration verification
Integration verification runs in main repo after all parallel features complete.

## AC-010: Sequential unchanged
Sequential path (`ag auto epic` without `--parallel`) unchanged.
