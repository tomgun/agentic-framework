# Acceptance Criteria: F-0114 - Scope & Diff Verification

## Overview
Structural verification tools that help humans review agent changes efficiently. Based on Karpathy's insight that agents make unintended side effects - this feature makes drift visible rather than trying to prevent it through behavioral instructions.

## Acceptance Criteria

- [x] New file `.agentic/tools/scope_check.sh` created
- [x] scope_check.sh reads IN_SCOPE from WIP.md
- [x] scope_check.sh warns (not blocks) on files outside declared scope
- [x] scope_check.sh runs silently when no WIP.md or no scope declared
- [x] pre-commit-check.sh shows diff stats at start of output
- [x] pre-commit-check.sh displays total lines changed
- [x] pre-commit-check.sh calls scope_check.sh and shows warnings
- [x] wip.sh template includes IN_SCOPE and OUT_OF_SCOPE fields
- [x] feature_start.md mentions scope declaration
- [x] PRINCIPLES.md has 2 new framework design principles (structural ones)
- [x] delegation_heuristics.md has 2 new meta-insights (general advice)
- [x] Principles follow structural-over-behavioral approach

## Design Rationale

This feature follows the principle that **instructions don't change agent behavior** - structural constraints and automated verification do:

- **Diff stats**: Show information, let human judge (not "is this too big?")
- **Scope warnings**: Inform about drift, don't block (human decides if intentional)
- **Principles**: Document meta-insights so they're not forgotten

The goal is to make human review *efficient*, not *unnecessary*.
