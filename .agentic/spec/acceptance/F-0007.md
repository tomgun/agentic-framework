# F-007: Small Batch Development - Acceptance Criteria

**Feature**: Work in small, isolated batches - one feature at a time per agent

**Version**: 0.7.0

---

## Acceptance Criteria

### Principle Definition

- [x] **AC-001**: PRINCIPLES.md includes Small Batch Development as NON-NEGOTIABLE
- [x] **AC-002**: agent_operating_guidelines.md has Small Batch section at top
- [x] **AC-003**: Rules clearly state: one feature at a time per agent
- [x] **AC-004**: Rules clearly state: max 5-10 files per commit

### One Feature At A Time

- [x] **AC-010**: Agents must complete current feature before starting new one
- [x] **AC-011**: Multi-agent with worktrees is documented as exception (per-agent rule)
- [x] **AC-012**: "STOP and re-plan" conditions are clearly documented

### Batch Size Enforcement

- [x] **AC-020**: `pre-commit-check.sh` warns if >10 files changed
- [x] **AC-021**: Warning message suggests splitting into smaller batches
- [x] **AC-022**: Warning is non-blocking (allows override)

### Acceptance Criteria Requirement

- [x] **AC-030**: Agents must have acceptance criteria before coding (rough OK)
- [x] **AC-031**: `feature_implementation.md` has Gate 1: Acceptance Criteria Exist
- [x] **AC-032**: If no criteria, agent escalates to HUMAN_NEEDED.md

# Check Small Batch in PRINCIPLES.md

## Test Scenarios

### Scenario 1: Normal Batch Size

**Given**: Agent implementing feature touching 5 files
**When**: Agent runs pre-commit check
**Then**: Check passes, no warnings about batch size

### Scenario 2: Large Batch Warning

**Given**: Agent has staged 15 files
**When**: Agent runs pre-commit check
**Then**: Warning shown: "15 files changed - consider splitting"

### Scenario 3: Multi-Agent Parallel Work

**Given**: Two agents in separate worktrees
**When**: Agent 1 works on F-001, Agent 2 works on F-0002
**Then**: Each agent follows one-feature-at-a-time in their worktree

### Scenario 4: Missing Acceptance Criteria

**Given**: Feature with no acceptance criteria
**When**: Agent starts implementing
**Then**: Agent stops, creates rough criteria or escalates to HUMAN_NEEDED.md
