# NFR-0003: Small Batch Commits — Acceptance Criteria

## Acceptance Criteria

- AC-001: Pre-commit hook counts staged files and blocks if count exceeds `max_files_per_commit` setting
- AC-002: Default thresholds are profile-aware: Discovery=15, Formal=10
- AC-003: Threshold is configurable via `ag set max_files_per_commit <N>`
- AC-004: Advisory batch-size warnings appear on feature branches (not blocking)

## Tests

- `tests/validate_framework.sh`: batch size enforcement checks
- `pre-commit-check.sh`: file count gate

## NFR Compliance

This IS an NFR — self-referential compliance not applicable.

## Out of Scope

- Blocking on line count (handled by `max_added_lines` setting separately)
