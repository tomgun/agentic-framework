# F-0236: Autonomous Plan Convergence Loop with Expert Reviewers

## Acceptance Criteria

### Settings & Configuration (P1 — MVP)

- [ ] **AC-001**: `plan_review_convergence` setting exists with values `auto | manual` (default: auto when plan_review_enabled=yes), profile defaults: discovery=manual, formal=auto, autonomous_formal=auto
- [ ] **AC-002**: `plan_review_reviewers` setting exists as comma-separated list (default: critic,advocate), parsed via `get_setting_list()` helper
- [ ] **AC-003**: `plan_review_max_iterations` is now enforced as hard limit (was advisory) — loop terminates and escalates at max

### Convergence Detection (P1 — MVP)

- [ ] **AC-004**: `ConvergenceDetector` parses Critic output for "High-Confidence Concerns" section — empty section = strong convergence signal
- [ ] **AC-005**: Convergence requires iteration >= 2 (minimum 2 rounds prevents rubber-stamping)
- [ ] **AC-006**: Convergence checks explicit checkbox pattern `- [x] Plan is fundamentally sound` in reviewer outputs
- [ ] **AC-007**: Expert reviewer high-severity findings also block convergence
- [ ] **AC-008**: Resilient parsing with regex fallbacks — if parsing fails entirely, default is NOT converged (safe default)

### Convergence Loop (P1 — MVP)

- [ ] **AC-009**: `ConvergenceLoop.run()` spawns all configured reviewers in parallel each iteration
- [ ] **AC-010**: After reviewer outputs collected, `PlanSynthesizer` produces structured synthesis with High-Confidence Findings, Expert Advisories, and Revision Guidance
- [ ] **AC-011**: When not converged and iterations remain, Planner agent auto-revises plan using synthesis + Revision Guidance
- [ ] **AC-012**: When converged in autonomous mode (`ag auto task`), plan status set to APPROVED automatically
- [ ] **AC-013**: When converged in interactive mode, plan presented to user for final approval
- [ ] **AC-014**: When max iterations reached without convergence, plan status set to ESCALATED and HUMAN_NEEDED entry created

### Guard & No-Op (P1 — MVP)

- [ ] **AC-015**: `plan_review_convergence: auto` is a no-op when `plan_review_enabled: no` — `ConvergenceLoop.run()` returns early
- [ ] **AC-016**: `plan_review_convergence: manual` preserves current user-driven behavior (no auto-iteration)

### Reviewer Catalog (P1 — MVP)

- [ ] **AC-017**: `reviewer_roles.json` catalog defines roles with agent_file, mandate, required flag, and model_tier
- [ ] **AC-018**: `critic` and `advocate` are `required: true` — always present even if omitted from `plan_review_reviewers` list
- [ ] **AC-019**: Unknown role names in settings produce a warning (not error) and are skipped
- [ ] **AC-020**: `get_setting_list()` parses both comma-separated ("critic,advocate") and bracket-list ("[critic, advocate]") formats

### Expert Reviewer Agents (P2 — Enhancement)

- [ ] **AC-021**: 6 expert reviewer agent files created: ux_designer, architect, qa_expert, security_expert, ops_expert, db_expert
- [ ] **AC-022**: Each expert follows same output structure as Critic (High-Confidence Concerns, Possible Concerns, Observations) for uniform synthesis
- [ ] **AC-023**: Experts supplement Critic+Advocate — they don't replace the dialectical core

### Critic/Advocate Updates (P1 — MVP)

- [ ] **AC-024**: Critic agent output format includes "Convergence Signal" checkbox section
- [ ] **AC-025**: Advocate agent output format includes "Convergence Signal" checkbox section

### CLI Entry Point (P2 — Enhancement)

- [ ] **AC-026**: `plan_convergence.py` has both Python API (`ConvergenceLoop` class) and `__main__` CLI for bash callers
- [ ] **AC-027**: CLI exit codes: 0=approved, 1=draft/reviewing (runs loop), 2=not found or escalated
