# F-0185: MCP Server for Agent Coordination

**ADR**: ADR-001, Phase 6, Section 4
**Dependencies**: F-0177, F-0180, F-0184

## Acceptance Criteria

- [ ] **AC-001**: Python MCP server exposes 8 tools: `claim_feature`, `release_feature`, `transition_state`, `get_unblocked`, `subscribe_state`, `report_status`, `request_review`, `submit_review`
- [ ] **AC-002**: Each MCP tool is a thin wrapper delegating to existing Python classes (state_machine.py, review.py, components.py)
- [ ] **AC-003**: `ag mcp start | stop | status` commands manage the MCP server process
- [ ] **AC-004**: Graceful degradation: if MCP server is not running, framework uses file-based coordination with no errors
- [ ] **AC-005**: MCP server coexists with existing `control.py` Unix socket (different concerns, same process space)
- [ ] **AC-006**: File-based persistence remains authoritative — MCP caches state in memory but files are source of truth
- [ ] **AC-007**: Unit tests cover tool invocation, delegation, and fallback behavior
