# F-0241: Central QA Registry

## Acceptance Criteria

### AC-001: qa_registry.py scanner (P1)
- [ ] Scans `tests/validate_framework.sh` for `# F-XXXX:` section headers
- [ ] Scans `tests/test_*.py` for `@feature F-XXXX` decorators or `# feature: F-XXXX` comments
- [ ] Scans `tests/llm/tests/*.sh` for feature references
- [ ] Scans `.agentic/lib/auto/scenarios/*.yaml` for scenario coverage
- [ ] Scans `.agentic/lib/hooks/pre-commit-check.sh` for gate catalog
- [ ] Scans `.agentic/lib/checklists/*.md` for checklist coverage
- [ ] Scans `tests/infrastructure/` for structural/mutation tests
- [ ] Reads `.agentic/spec/FEATURES.md` to enumerate all features and their status

### AC-002: QA_REGISTRY.md output (P1)
- [ ] Generates `docs/QA_REGISTRY.md` with all 4 sections: Test Methods Catalog, Feature-to-Test Matrix, Gap Analysis, Quick Run Guide
- [ ] Test Methods Catalog lists each category with file count and run command
- [ ] Feature-to-Test Matrix shows which test types cover each F-XXXX (sparse is expected)
- [ ] Gap Analysis identifies features with zero automated tests AND test files with no feature tags
- [ ] Quick Run Guide has three tiers: fast (static+unit), medium (+LLM), full (+scenarios)
- [ ] Output is valid markdown

### AC-003: ag qa command (P1)
- [ ] `ag qa` runs qa_registry.py and generates/regenerates QA_REGISTRY.md
- [ ] `ag qa --check` exits non-zero if QA_REGISTRY.md is stale (content differs from what would be generated)
- [ ] Command registered in ag.sh help

### AC-004: Freshness check in validate_framework.sh (P2)
- [ ] Advisory check (warn, not block) that QA_REGISTRY.md exists
- [ ] Advisory check that QA_REGISTRY.md is not older than 7 days (by file mtime)

### NFR Constraints (P1 — required)
- [ ] NFR-0003: Small batch — qa_registry.py + QA_REGISTRY.md + ag.sh change + validate_framework.sh check ≤ 10 files
- [ ] NFR-0004: Spec-first — this file exists before code
