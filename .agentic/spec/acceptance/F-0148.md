# F-0148: Spec Format Evolution — Acceptance Criteria

**Feature**: Evolves the acceptance criteria template with Behavior section, priority tags, verify-independently fields, and restructured Verification heading.

---

## Behavior (what the user needs — technology-agnostic)

When writing specs for new features, the template guides the author to separate "what the user needs" (Behavior) from "how to verify it" (ACs). Priority tags enable incremental delivery — ship P1 first, P2 later. Verify-independently fields make each AC group testable in isolation. Existing specs remain valid without modification.
