# F-0051: WIP Tracking - Acceptance Criteria

**Feature**: Track work-in-progress to prevent loss from interruptions

**Version**: 0.5.0

---

## Acceptance Criteria

### WIP Tool

- [x] **AC-001**: `wip.sh` script exists in `.agentic/tools/`
- [x] **AC-002**: `wip.sh start` creates .agentic/WIP.md with feature, agent, timestamp
- [x] **AC-003**: `wip.sh checkpoint` updates progress and timestamp
- [x] **AC-004**: `wip.sh complete` removes .agentic/WIP.md
- [x] **AC-005**: `wip.sh check` reports WIP status and staleness

### .agentic/WIP.md Lock File

- [x] **AC-010**: .agentic/WIP.md created in .agentic/ directory when work starts
- [x] **AC-011**: .agentic/WIP.md contains: feature ID, agent/environment, start time
- [x] **AC-012**: .agentic/WIP.md contains: files being edited, progress checklist
- [x] **AC-013**: .agentic/WIP.md contains: recovery instructions

### Staleness Detection

- [x] **AC-020**: <5 min since last checkpoint: "Recent"
- [x] **AC-021**: 5-60 min since last checkpoint: "Normal"
- [x] **AC-022**: >60 min since last checkpoint: "STALE" (likely interrupted)

### Integration with Hooks

- [x] **AC-030**: `pre-commit-check.sh` blocks commit if .agentic/WIP.md exists
- [x] **AC-031**: `session_start.md` checks for interrupted WIP first
- [x] **AC-032**: Claude hooks checkpoint WIP on PreCompact

---

## Validation Commands

```bash
# Test WIP start
bash .agentic/tools/wip.sh start F-0001 "Implementing login" "src/auth.ts"
cat .agentic/WIP.md

# Test WIP checkpoint
bash .agentic/tools/wip.sh checkpoint "Added login form"
cat .agentic/WIP.md

# Test WIP check
bash .agentic/tools/wip.sh check

# Test WIP complete
bash .agentic/tools/wip.sh complete
ls .agentic/WIP.md  # Should not exist

# Test pre-commit blocks WIP
bash .agentic/tools/wip.sh start F-0002 "Test" "file.txt"
bash .agentic/hooks/pre-commit-check.sh  # Should fail
```

## Test Scenarios

### Scenario 1: Normal Work Session

**Given**: Agent starting work on feature
**When**: Agent runs `wip.sh start F-0001 "description" "files"`
**Then**: .agentic/WIP.md created with correct contents

### Scenario 2: Interrupted Work Detection

**Given**: .agentic/WIP.md exists from previous session (>60 min old)
**When**: New agent starts session
**Then**: `session_start.md` detects stale WIP, prompts recovery

### Scenario 3: Commit Blocked by WIP

**Given**: .agentic/WIP.md exists (work incomplete)
**When**: Agent tries to commit
**Then**: `pre-commit-check.sh` blocks commit, explains WIP must be completed

### Scenario 4: Token Limit Recovery

**Given**: Agent hit token limit, .agentic/WIP.md exists
**When**: New session starts
**Then**: Agent runs `wip.sh check`, sees interrupted work, follows recovery.md
