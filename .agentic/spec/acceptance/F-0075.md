# F-0075: Traceability

## Acceptance Criteria

- [ ] AC1: Features link to acceptance criteria files
- [ ] AC2: Implementation can be traced to feature requirement
- [ ] AC3: Tests can be traced to acceptance criteria
- [ ] AC4: Changes have feature ID in commit messages
- [ ] AC5: FEATURES.md shows implementation state
- [ ] AC6: Agent maintains traceability during development

## Verification

- **Automated**:
  - FEATURES.md references acceptance files
  - Feature status includes impl-state
  - Commit guidelines mention feature IDs
- **Manual**: Can trace from requirement to implementation
- **Profile**: Formal only
