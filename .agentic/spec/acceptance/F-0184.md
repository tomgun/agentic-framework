# F-005: Epic Decomposition

**ADR**: ADR-001, Phase 5, Section 2
**Dependencies**: F-0179, F-014

## Acceptance Criteria

- [ ] **AC-001**: `ag decompose F-XXXX` analyzes epic acceptance criteria and proposes child features scoped to components
- [ ] **AC-002**: Decomposition uses component registry (F-0179) to scope child features to the correct component
- [ ] **AC-003**: Decomposition routes through `review_decomposition` checkpoint before creating child features
- [ ] **AC-004**: Child features have `Parent: F-XXXX` field linking to the epic
- [ ] **AC-005**: Epic status is derived from children: epic ships when all children ship + integration verification passes
- [ ] **AC-006**: Regression cascade: if a child regresses (backward transition), epic status recomputes automatically
- [ ] **AC-007**: `query_features.py --children F-XXXX` shows all child features with their status
- [ ] **AC-008**: Epic acceptance criteria are product-level; child acceptance criteria are component-scoped
- [ ] **AC-009**: Unit tests cover decomposition, cascade, parent-child status derivation, and regression propagation
