# F-011: Framework Architecture Decision Records (ADRs)

## Description
Document WHY framework decisions were made, not just what. Prevents future contributors from undoing intentional decisions.

## Acceptance Criteria

### A-0101-01: ADR Directory Exists
- [ ] `docs/adr/` directory exists in framework repo
- [ ] `docs/adr/README.md` explains purpose and format

### A-0101-02: ADR Format Defined
- [ ] ADRs follow consistent format: Status, Context, Decision, Rationale, Consequences
- [ ] Format documented in README.md

### A-0101-03: First ADR Documents Bootstrap Decision
- [ ] `docs/adr/001-claude-md-self-contained.md` exists
- [ ] Documents why CLAUDE.md must be self-contained
- [ ] Explains intentional "duplication" with agent_operating_guidelines.md

### A-0101-04: ADRs Referenced in CONTEXT_PACK
- [ ] CONTEXT_PACK.md mentions ADR directory
- [ ] Agents know to check ADRs before changing framework architecture

### A-0101-05: Framework Development Workflow Updated
- [ ] FRAMEWORK_QUICK_START.md mentions creating ADRs for significant decisions
- [ ] Contributors know when to create ADRs

## Validation
```bash
# Check ADR directory exists
test -d docs/adr && echo "PASS: ADR directory exists"

# Check first ADR exists
test -f docs/adr/001-claude-md-self-contained.md && echo "PASS: First ADR exists"

# Check README exists
test -f docs/adr/README.md && echo "PASS: ADR README exists"
```

## Notes
- ADRs are for FRAMEWORK decisions, not project decisions
- Projects using framework have their own ADR location if enabled
