## Test Scenarios

### Scenario 1: Setting Up Multi-Agent

**Given**: Single-agent project
**When**: User wants parallel development
**Then**: Create worktrees per feature, open in separate IDE windows

### Scenario 2: Agent Claims Feature

**Given**: Two agents ready to work
**When**: Agent 1 claims F-0001
**Then**: Agent 1 updates AGENTS_ACTIVE.md, Agent 2 sees it's taken

### Scenario 3: Parallel Implementation

**Given**: Agent 1 on F-0001, Agent 2 on F-0002 (independent features)
**When**: Both implement simultaneously
**Then**: No conflicts, each commits to their branch

### Scenario 4: Feature Dependency

**Given**: F-0002 depends on F-0001
**When**: Agent 2 needs F-0001
**Then**: Agent 2 waits or helps Agent 1, merges F-0001 first
