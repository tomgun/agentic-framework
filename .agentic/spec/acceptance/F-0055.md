# F-0055: Anti-Hallucination Rules - Acceptance Criteria

**Feature**: Non-negotiable rules preventing agents from making things up

**Version**: 0.3.5

---

## Acceptance Criteria

### Rules Documented

- [x] **AC-001**: Anti-hallucination section exists in agent_operating_guidelines.md
- [x] **AC-002**: Marked as "NON-NEGOTIABLE"
- [x] **AC-003**: Explicitly states "NEVER make things up"

### Rule 1: Never Fabricate

- [x] **AC-010**: Agents must state when they don't know something
- [x] **AC-011**: Agents must look up uncertain information (Context7, docs, web)
- [x] **AC-012**: Agents must ask human if cannot verify
- [x] **AC-013**: Agents must never guess or invent plausible-sounding information

### Rule 2: Immediate Documentation

- [x] **AC-020**: Blockers identified during work go to HUMAN_NEEDED.md immediately
- [x] **AC-021**: Not just mentioned in chat - actually added to file
- [x] **AC-022**: If session ends abruptly, blocker is still documented

### Rule 3: Auto-Journal

- [x] **AC-030**: Progress logged at natural checkpoints
- [x] **AC-031**: Don't wait for session end or user reminders
- [x] **AC-032**: Two-tier logging (SESSION_LOG + JOURNAL)

### Verification Sources

- [x] **AC-040**: Context7 integration documented as preferred source
- [x] **AC-041**: Manual verification fallback documented
- [x] **AC-042**: Version matching emphasized (use docs for correct version)

## Test Scenarios

### Scenario 1: Unknown API

**Given**: Agent asked about unfamiliar library API
**When**: Agent doesn't know the answer
**Then**: Agent says "I'm not certain, let me look this up" and searches

### Scenario 2: Fabrication Prevented

**Given**: Agent tempted to make up configuration option
**When**: Agent follows anti-hallucination rules
**Then**: Agent admits uncertainty, finds actual documentation

### Scenario 3: Blocker Documentation

**Given**: Agent discovers API key is needed
**When**: Agent identifies blocker
**Then**: Agent IMMEDIATELY adds to HUMAN_NEEDED.md (not just mentions in chat)

### Scenario 4: Version-Correct Docs

**Given**: Project uses React 18.2
**When**: Agent needs to check React API
**Then**: Agent uses React 18.x docs, not React 19 or 17 docs
