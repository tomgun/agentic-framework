# F-0187: Multi-Repo Umbrella

**ADR**: ADR-001, Phase 7, Section 6
**Dependencies**: F-0179, F-0186

## Acceptance Criteria

- [ ] **AC-001**: Component registry supports `Repo` column for cross-repo projects
- [ ] **AC-002**: Umbrella pattern: orchestrator in main repo, components in parallel repos
- [ ] **AC-003**: Cross-repo contract checking validates interface compatibility between components
- [ ] **AC-004**: User input collection: structured prompts for vision, style refs, research before decomposition begins
- [ ] **AC-005**: Single-repo projects are unaffected (Repo column is optional)
- [ ] **AC-006**: Unit tests cover multi-repo resolution and contract validation
