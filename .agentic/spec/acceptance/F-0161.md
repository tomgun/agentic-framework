# F-0161: Autonomous Verify Mode — Acceptance Criteria

**Feature**: Test-fix loop (`ag auto verify`).

---

## Acceptance Criteria

- [ ] **AC-001**: `ag auto verify` runs project test suite and captures output
- [ ] **AC-002**: On test failure, spawns fresh Claude instance with failure output + relevant code
- [ ] **AC-003**: Claude fixes are applied and tests re-run automatically
- [ ] **AC-004**: Loop stops when all tests pass or max iterations reached
- [ ] **AC-005**: Progress reported via control socket (test pass/fail counts per iteration)
- [ ] **AC-006**: Max iterations configurable (default: 10)
- [ ] **AC-007**: Final report shows iterations taken, tests fixed, tests still failing
