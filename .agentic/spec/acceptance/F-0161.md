# F-0161: Autonomous Verify Mode — Acceptance Criteria

**Feature**: Test-fix loop (`ag auto verify`).
**Status**: shipped

---

## Acceptance Criteria

- [x] **AC-001**: `ag auto verify` runs project test suite and captures output
- [x] **AC-002**: On test failure, spawns fresh Claude instance with failure output + relevant code
- [x] **AC-003**: Claude fixes are applied and tests re-run automatically
- [x] **AC-004**: Loop stops when all tests pass or max iterations reached
- [x] **AC-005**: Progress reported via control socket (test pass/fail counts per iteration)
- [x] **AC-006**: Max iterations configurable (default: 10)
- [x] **AC-007**: Final report shows iterations taken, tests fixed, tests still failing
