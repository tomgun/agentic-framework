# Acceptance Criteria: F-0110 - Feature Hierarchy Query

## Overview
Add `--children` query to `query_features.py` to list children/descendants of a feature.

## Acceptance Criteria

### Core Functionality
- [x] `query_features.py --children=F-XXXX` returns direct children of specified feature
- [x] `--recursive` flag shows all descendants with indented tree format
- [x] Output includes status summary (X shipped, Y in_progress, Z planned)
- [x] Recursive mode shows "descendants" count, non-recursive shows "children"

### Error Handling
- [x] Returns graceful message when no children exist ("No children found for F-XXXX")
- [x] Shows error when parent F-ID doesn't exist ("Error: Feature F-XXXX not found")
- [x] Shows error for invalid feature ID format ("Error: Invalid feature ID format")

### Filter Support
- [x] `--children` combined with `--status` filters children by status
- [x] `--recursive` combined with `--status` filters descendants by status, maintains tree structure

### Edge Cases
- [x] Works with both flat (FEATURES.md) and hierarchical (features/*/*.md) layouts
- [x] Handles circular references gracefully (cycle detection)

## Verification Commands

```bash
# 1. Direct children
python3 .agentic/tools/query_features.py --children=F-0001 --file=tests/fixtures/sample_features.md
# Expected: Lists F-0002, F-0003 with statuses + summary

# 2. Recursive descendants
python3 .agentic/tools/query_features.py --children=F-0001 --recursive --file=tests/fixtures/sample_features.md
# Expected: Indented tree showing F-0002, F-0006, F-0007, F-0003

# 3. No children
python3 .agentic/tools/query_features.py --children=F-0005 --file=tests/fixtures/sample_features.md
# Expected: "No children found for F-0005"

# 4. Non-existent parent
python3 .agentic/tools/query_features.py --children=F-9999 --file=tests/fixtures/sample_features.md
# Expected: "Error: Feature F-9999 not found" (exit 1)

# 5. Invalid format
python3 .agentic/tools/query_features.py --children=invalid --file=tests/fixtures/sample_features.md
# Expected: "Error: Invalid feature ID format" (exit 1)

# 6. Combined with status filter
python3 .agentic/tools/query_features.py --children=F-0001 --status=planned --file=tests/fixtures/sample_features.md
# Expected: Only planned children shown

# 7. Run tests
python3 -m pytest tests/test_query_features.py -v
# Expected: All tests pass
```
