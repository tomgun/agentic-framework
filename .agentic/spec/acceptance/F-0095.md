# F-021: Cross-Platform Tool Compatibility - Acceptance Criteria

## AC-001: macOS Compatibility

**Given** all scripts in `.agentic/tools/`
**When** run on macOS (BSD userland)
**Then**:
- No BSD sed syntax errors
- No GNU-specific flags used without fallback
- All scripts execute successfully

## AC-002: Linux Compatibility

**Given** all scripts in `.agentic/tools/`
**When** run on Linux (GNU userland)
**Then**:
- All scripts execute successfully
- Same behavior as on macOS

## AC-003: Awk Over Sed for Complex Operations

**Given** scripts that need complex text replacement
**When** implementing the logic
**Then**:
- Use awk instead of sed for multi-line operations
- Use awk instead of sed for in-place edits with complex patterns
- Sed only used for simple substitutions

## AC-004: Status.sh Cross-Platform

**Given** `.agentic/tools/status.sh`
**When** run on macOS
**Then**:
- All field updates work (focus, progress, next, blocker)
- No "invalid command code" errors
- Correct file modification

## AC-005: Testing Guidance

**Given** FRAMEWORK_DEVELOPMENT.md
**When** testing framework changes
**Then** it mentions:
- Test on both macOS and Linux if possible
- Known platform differences to watch for
- Awk preference for complex text processing
