# F-0208: Deferred Documentation Mode - Acceptance Criteria

**Feature**: `docs_mode` setting — inline (default) or deferred doc updates
**Plan**: `.agentic/journal/plans/F-0208-plan.md`

---

## Acceptance Criteria

### P1 — Core (MVP)

- [ ] **AC-001**: `docs_mode` setting exists in STACK.template.md with default `inline`. Profile defaults in profiles.conf: all three profiles default to `inline`. `ag set docs_mode deferred` succeeds; `ag set docs_mode invalid` fails with error.

- [ ] **AC-002**: `show_all_settings()` in settings.sh includes `docs_mode`. `ag settings` displays it with correct source (explicit/preset/default).

- [ ] **AC-003**: When `docs_mode: deferred` and `docs_gate: warning|blocking`, `ag done` creates/appends to `.agentic/deferred-docs.json` with entries containing `feature_id`, `timestamp`, `files_changed`, `description`, `stale_docs` (path + type), `commit_sha`. The drift check still runs (awareness) but the blocking prompt is suppressed.

- [ ] **AC-004**: When `docs_gate: off`, no deferred entries are created regardless of `docs_mode`. The doc lifecycle section is skipped entirely.

- [ ] **AC-005**: When `docs_mode: inline` (default), existing behavior is unchanged — doc lifecycle fires normally in `ag done`.

- [ ] **AC-006**: `ag docs generate` reads `deferred-docs.json`, calls `docs.sh --trigger feature_done --manifest <fid>` per entry, and removes completed entries one-by-one. `ag docs generate F-XXXX` filters to a single feature.

- [ ] **AC-007**: Deferred log uses `$MAIN_PROJECT_ROOT/.agentic/deferred-docs.json` — writes to main repo root even when run from a worktree.

### P2 — Instruction Updates

- [ ] **AC-008**: implementing-features SKILL.md Step 6 has deferred branch: skip inline doc updates when `docs_mode: deferred`, with framework-dev carve-out.

- [ ] **AC-009**: completing-work SKILL.md Step 2b has deferred branch: skip doc verification when `docs_mode: deferred`.

- [ ] **AC-010**: memory-seed.md updated with deferred docs rules in "When committing" and "When work is done" sections. Sentinels updated.
