## Test Scenarios

### Scenario 1: User-Facing Feature

**Given**: Agent implemented new UI feature
**When**: Agent runs smoke test checklist
**Then**: Agent runs app, clicks through feature, verifies no errors

### Scenario 2: Backend-Only Change

**Given**: Agent implemented internal refactoring
**When**: Agent considers smoke test
**Then**: Smoke test optional (not user-facing), but still recommended

### Scenario 3: Smoke Test Failure

**Given**: Agent runs app after implementation
**When**: Console shows JavaScript error
**Then**: Agent fixes error, re-runs smoke test until clean

### Scenario 4: Missing Smoke Test

**Given**: Agent claims feature is "done"
**When**: Feature has obvious bug (button doesn't work)
**Then**: This failure indicates smoke test was skipped - process failure
