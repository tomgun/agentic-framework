# F-0116: Maintainability Enforcement Gates

## Summary

Enforce maintainability through automated gates that BLOCK commits when quality standards aren't met.

## Acceptance Criteria

### AC-001: Test Execution Gate
- [x] Pre-commit check runs tests from STACK.md (`test_fast:` or `test:`)
- [x] Whitelist-based execution (only known test runners allowed)
- [x] Timeout protection (configurable via `TEST_TIMEOUT`, default 300s)
- [x] Tests failing = commit BLOCKED
- [x] Works on macOS (gtimeout) and Linux (timeout)

### AC-002: Complexity Limits Gate
- [x] Counts ADDED lines only (not deletions, not total)
- [x] Configurable via STACK.md:
  - `max_files_per_commit` (default: 10)
  - `max_added_lines` (default: 500)
  - `max_code_file_length` (default: 500)
- [x] File-type aware (only checks code extensions)
- [x] Exceeding limits = commit BLOCKED

### AC-003: Escape Hatches
- [x] `SKIP_TESTS=1` skips test execution
- [x] `SKIP_COMPLEXITY=1` skips complexity limits
- [x] Escape hatches BLOCKED on main/master branches
- [x] Shows warning when escape hatches used
- [x] Documented in git_workflow.md

### AC-004: Core Profile Enforcement
- [x] Core profile enforces tests for changed files
- [x] Core profile enforces complexity limits
- [x] Documented in agent_operating_guidelines.md

### AC-005: WIP Auto-Creation
- [x] `wip.sh start F-XXXX --auto` creates minimal WIP
- [x] Silent exit if WIP already exists

### AC-006: Acceptance Frontmatter Parsing
- [x] doctor.py parses YAML frontmatter from acceptance files
- [x] Graceful fallback (regex) if PyYAML not installed
- [x] validate_acceptance_tests() checks for validation commands

### AC-007: Migration Support
- [x] upgrade.sh adds complexity_limits section to STACK.md
- [x] upgrade.sh adds frontmatter to acceptance files
- [x] Suggests test_fast addition when only test: exists

## Verification Commands

```bash
# Run framework validation
bash tests/validate_framework.sh

# Test pre-commit check
bash .agentic/hooks/pre-commit-check.sh

# Test escape hatch blocking on main
git checkout main
```
