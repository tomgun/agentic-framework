# F-0191: Dialectical Plan Review - Acceptance Criteria

## AC-001: Controlled by plan_review_enabled

**Given** a project with STACK.md
**When** `plan_review_enabled: yes` is set
**Then** the plan-review loop uses dialectical mechanism (Critic + Advocate), no separate `plan_dialectical_review` setting exists

## AC-002: Critic Agent Definition

**Given** the framework's agent library
**When** a plan needs review
**Then** a Critic agent exists at `.agentic/lib/agents/claude/subagents/plan-critic-agent.md` with:
- Adversarial mandate (find flaws, risks, blind spots)
- Structured output (High-Confidence Concerns, Possible Concerns, Assumptions Worth Verifying)
- Fresh context (reads plan independently)
- No verdict authority (never says APPROVED/REVISION_NEEDED)
- Iteration awareness (if iteration > 1, reads Review History but forms OWN assessment)

## AC-003: Advocate Agent Definition

**Given** the framework's agent library
**When** a plan needs review
**Then** an Advocate agent exists at `.agentic/lib/agents/claude/subagents/plan-advocate-agent.md` with:
- Defensive mandate (explain trade-offs, defend decisions, articulate strengths)
- Structured output (Core Strengths, Trade-offs Acknowledged, Risk Management, Honest Weaknesses)
- Fresh context (reads plan independently)
- Explains WHY the plan made its choices
- Iteration awareness (if iteration > 1, reads Review History but forms OWN assessment)

## AC-004: Workflow Definition

**Given** the framework's workflow library
**When** dialectical review is needed
**Then** `.agentic/lib/workflows/dialectical_review.md` defines the mechanism with:
- Diagram showing Critic + Advocate running in parallel
- Synthesis format with Revision Guidance section
- Iteration flow (Proceed/Revise/Reject)
- Configuration reference (controlled by `plan_review_enabled`)
- Cross-tool adaptation notes (Claude Code, Cursor, Copilot, Codex)

## AC-005: Context Manifests

**Given** the framework's context manifest system
**When** Critic or Advocate agents are spawned
**Then** context manifests exist at `.agentic/lib/agents/context-manifests/plan-critic-agent.yaml` and `plan-advocate-agent.yaml` with ~3000 token budgets

## AC-006: Planning Skill Integration

**Given** a plan in Claude Code
**When** `plan_review_enabled: yes` in STACK.md
**Then** the planning skill runs dialectical review as part of the plan-review loop (not a separate step), with user deciding Proceed/Revise/Reject

## AC-007: ag plan Integration

**Given** `plan_review_enabled: yes` in STACK.md
**When** `ag plan F-XXXX` is run
**Then** Critic + Advocate instructions appear as THE review mechanism (Step 2), not a separate step after a single-reviewer loop
