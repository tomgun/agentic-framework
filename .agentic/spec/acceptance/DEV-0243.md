# Acceptance Criteria: DEV-004 Complexity Tier Experiments

## Overview

Empirically compare framework outcomes across three real configuration profiles (discovery, formal, autonomous_formal) by running the same build task N times per tier and collecting structured metrics.

## Acceptance Criteria

### AC1: CLI dry-run works without errors

```
python3 .agentic/lib/auto/tier_experiment.py \
  --project-root . \
  --experiment complexity_tiers \
  --dry-run
```

- Prints exactly 9 planned runs (3 tiers × 1 scenario × 3 repetitions)
- No errors or tracebacks
- Shows tier names: discovery, formal, autonomous_formal
- Completes without spawning any agents

### AC2: Unit tests pass

```
pytest tests/test_tier_experiment.py -v
```

- All tests pass
- Covers: TierMetrics defaults, ExperimentResult.by_tier(), collect_metrics() for each metric type, load_experiment_config(), _print_dry_run(), _print_comparison()

### AC3: ag auto tier-experiment help works

```
ag auto tier-experiment --help
```

- Shows usage without error
- Lists --experiment, --dry-run, --single-run, --json flags

### AC4: ag auto wrapper routes correctly

```
ag auto tier-experiment --experiment complexity_tiers --dry-run
```

- Same output as AC1 (via ag wrapper)
- No "Unknown auto command" error

### AC5: ag auto --help includes the new command

```
ag auto --help
```

- Output includes `tier-experiment` in the COMMANDS section

### AC6: complexity_tiers.yaml validates

The experiment config at `.agentic/lib/auto/experiments/complexity_tiers.yaml`:
- Has 3 tiers: discovery, formal, autonomous_formal
- Each tier has `settings.profile` key
- Each formal/autonomous_formal tier has `review_merge: skip`
- Has `scenarios: [todo_app]`
- Has `repetitions: 3`

### AC7: TierMetrics collection is best-effort

Given a project directory after a completed run:
- Missing tools (ruff) → `code_quality_errors: 0` (not error)
- Missing JSONL log → `violations: []` (not error)
- Missing framework.log → `framework_log_events: 0` (not error)
- None of these failures cause exceptions

### AC8: LLM test routes tier experiment requests correctly

```
tests/llm/tests/096_tier_experiment_trigger.sh
```

- Agent routes "run empirical comparison of discovery/formal/autonomous_formal" to `ag auto tier-experiment`
- Agent does NOT confuse with `ag auto verify-framework`

### AC9: ExperimentResult serializes to JSON

```python
result = ExperimentResult("complexity_tiers")
result.runs.append(TierMetrics(tier="discovery", scenario="todo_app", run_number=1))
json.dumps(result.to_dict())  # No error
```

### AC10: Comparison report shows cross-tier table

When given populated ExperimentResult, `_print_comparison()` outputs:
- A table with universal metrics (app_runs, tests_pass, test_count, wall_time, etc.) across tiers
- Per-tier framework-specific breakdown (spec_created, plan_created, etc.)
- Violation summary per tier
- Note about statistical limitations of n=3
