# F-0002: Profile Selection (Discovery vs Formal)

## Acceptance Criteria

- [ ] AC1: scaffold.sh accepts `--profile discovery` and `--profile formal` flags
- [ ] AC2: AGENTIC_PROFILE environment variable overrides default
- [ ] AC3: Discovery profile creates: STACK.md, CONTEXT_PACK.md, OVERVIEW.md, JOURNAL.md, HUMAN_NEEDED.md
- [ ] AC4: Discovery profile does NOT create: spec/ directory, PRD.md, FEATURES.md
- [ ] AC5: Formal profile creates all Discovery files PLUS spec/ directory with PRD.md, FEATURES.md, ISSUES.md, etc.
- [ ] AC6: STACK.md records which profile was selected
- [ ] AC7: Invalid profile value produces clear error message

## Verification

- **Automated**:
  - scaffold.sh has --profile flag (grep)
  - Test Discovery install → no spec/ directory
  - Test Formal install → spec/ directory exists
- **Manual**: None required
- **Profile**: Both (meta-feature)
