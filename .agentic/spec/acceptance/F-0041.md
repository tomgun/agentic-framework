## Validation Commands

```bash
# Test journal.sh
bash .agentic/tools/journal.sh "2025-01-08" "Implemented login feature"
tail -20 JOURNAL.md

# Test status.sh
bash .agentic/tools/status.sh focus "Implementing F-0005"
head -20 STATUS.md

# Test feature.sh
bash .agentic/tools/feature.sh F-0005 status in_progress
grep "F-0005" spec/FEATURES.md

# Test blocker.sh
bash .agentic/tools/blocker.sh add "Need API key for payment gateway"
cat HUMAN_NEEDED.md
```

## Test Scenarios

### Scenario 1: Journal Entry

**Given**: Existing JOURNAL.md with history
**When**: Agent runs `journal.sh "2025-01-08" "session summary"`
**Then**: New entry appended, no read required, ~50 tokens

### Scenario 2: Feature Status Update

**Given**: Feature F-0005 with status "planned"
**When**: Agent runs `feature.sh F-0005 status in_progress`
**Then**: Status updated in FEATURES.md, other features unchanged

### Scenario 3: Add Blocker

**Given**: Development blocked by missing API key
**When**: Agent runs `blocker.sh add "Need payment API key"`
**Then**: New HN-#### entry added to HUMAN_NEEDED.md

### Scenario 4: Token Comparison

**Given**: JOURNAL.md is 2000 tokens
**When**: Agent needs to add one entry
**Then**: Using script: ~50 tokens. Reading file: ~2000 tokens. 40x savings.
