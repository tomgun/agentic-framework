# F-0200: Intent Journal + Reconciliation - Acceptance Criteria

**Feature**: Write-ahead log for multi-step ag.sh operations with crash recovery via reconciliation.

---

## Acceptance Criteria

### Prerequisite: State Machine Idempotency

- [ ] **AC-001**: `can_transition()` returns `(True, [info])` when already in target state (not `False`)
- [ ] **AC-002**: `transition()` short-circuits when current == target (no review checkpoint, no file write, no misleading logs)

### intents.py Module (PR 5a)

- [ ] **AC-003**: `.agentic/lib/auto/intents.py` exists with `write_intent()`, `checkpoint_step()`, `get_pending()`, `get_orphaned()`, `clear_intent()`, `cancel_intent()`, `adopt_orphans()` functions
- [ ] **AC-004**: All reads/writes use `_with_lock` from agents_helpers.py (fcntl exclusive lock)
- [ ] **AC-005**: Intent schema includes `previous_state` field (captured at write time for rollback)
- [ ] **AC-006**: Agent identity uses UUID `session_id` (not bare PID); PID for liveness detection only
- [ ] **AC-007**: Handles corrupt JSON gracefully (try/except, fallback to empty)
- [ ] **AC-008**: Creates `.agentic/session/` directory if not exists
- [ ] **AC-009**: Unit tests in `tests/test_intents.py` cover all functions

### cmd_implement Intent-Driven (PR 5b)

- [ ] **AC-010**: Intent logic extracted to `.agentic/lib/tools/intent-helpers.sh` (sourced by ag.sh, not inlined)
- [ ] **AC-011**: `cmd_implement` writes intent before any work, checkpoints each step, clears on completion
- [ ] **AC-012**: Each step is idempotent (register_wip, create_worktree, transition_state)
- [ ] **AC-013**: `state_enforcement` setting controls transition behavior: off (skip), advisory (warn), blocking (block)

### cmd_done Intent-Driven (PR 5c)

- [ ] **AC-014**: `cmd_done` writes intent before work, checkpoints each step, clears on completion
- [ ] **AC-015**: Reliability (crash recovery) ships unconditionally; state transitions gated behind `state_enforcement`
- [ ] **AC-016**: Process death mid-sequence → reconciler can resume from last checkpoint

### Reconciler + ag intent (PR 5d)

- [ ] **AC-017**: `phase_intents()` added to `ag sync` — reconciles current session's pending intents
- [ ] **AC-018**: Adopt-orphan mechanism: `ag sync` detects dead-PID intents and auto-adopts into current session
- [ ] **AC-019**: `ag intent list` shows all intents (current session + orphaned)
- [ ] **AC-020**: `ag intent clear F-XXXX` cancels intent and undoes completed steps (using `previous_state` for rollback)
- [ ] **AC-021**: Retry budget: 3 failures → escalate to HUMAN_NEEDED.md
- [ ] **AC-022**: Orphan detection: dead PID + 5 minutes → flagged as orphaned

### Instruction Files + Migration (PR 5e)

- [ ] **AC-023**: `state_enforcement` setting added to STACK.md template (discovery=off, formal=advisory)
- [ ] **AC-024**: `ag intent` documented in all 4 instruction file templates
- [ ] **AC-025**: auto_orchestration.md, memory-seed.md, DEVELOPER_GUIDE.md updated
- [ ] **AC-026**: upgrade.sh adds `.gitignore` entries + STACK.md setting for existing projects

### Integration Tests

- [ ] **AC-027**: Test: incomplete intent survives process death, reconciler resumes
- [ ] **AC-028**: Test: concurrent agents write intents for different features (lock contention)
- [ ] **AC-029**: Test: orphan detection with dead PID
- [ ] **AC-030**: Test: session isolation (agent A can't reconcile agent B's live intents)
