# F-0065: Error Message Quality

## Acceptance Criteria

- [ ] AC1: Scripts produce actionable error messages
- [ ] AC2: Errors explain what went wrong
- [ ] AC3: Errors suggest how to fix the issue
- [ ] AC4: Errors include relevant context (file path, expected value)
- [ ] AC5: No cryptic or technical-only error messages
- [ ] AC6: Exit codes are meaningful (0=success, non-zero=failure)

## Verification

- **Automated**:
  - Scripts use meaningful exit codes
  - Error messages include suggestions (grep for "try" or "should")
- **Manual**: Error messages help users fix issues
- **Profile**: Both
