# F-0001: Project Initialization - Acceptance Criteria

**Feature**: Initialize a new project with the Agentic framework

**Version**: 0.7.0

---

## Acceptance Criteria

### Installation

- [x] **AC-001**: `install.sh` can be run from unpacked framework directory
- [x] **AC-002**: `install.sh` accepts target project path as argument
- [x] **AC-003**: `install.sh` copies `.agentic/` to target project
- [x] **AC-004**: `install.sh` creates `VERSION` file in `.agentic/` with framework version
- [x] **AC-005**: `install.sh` displays success message with next steps

### Initialization Playbook

- [x] **AC-010**: Agent can read `.agentic/init/init_playbook.md` for guidance
- [x] **AC-011**: Playbook prompts for profile selection (Discovery vs Formal)
- [x] **AC-012**: Playbook prompts for project information (name, type, stack)
- [x] **AC-013**: Playbook guides through STACK.md setup

### Scaffold Script

- [x] **AC-020**: `scaffold.sh` creates root-level documents based on profile
- [x] **AC-021**: Discovery profile creates: `AGENTS.md`, `OVERVIEW.md`, `JOURNAL.md`, `HUMAN_NEEDED.md`, `CONTEXT_PACK.md`
- [x] **AC-022**: Formal profile also creates: `STATUS.md`, `spec/` directory structure
- [x] **AC-023**: All created files are valid markdown with correct templates

### Error Handling

- [x] **AC-030**: `install.sh` warns if `.agentic/` already exists in target
- [x] **AC-031**: `install.sh` fails gracefully with clear error if target doesn't exist

---

## Validation Commands

```bash
# Test installation
./install.sh /tmp/test-project
ls -la /tmp/test-project/.agentic/

# Test scaffold
cd /tmp/test-project
bash .agentic/init/scaffold.sh

# Verify created files
ls -la /tmp/test-project/
cat /tmp/test-project/STACK.md
```

---

## Test Scenarios

### Scenario 1: Fresh Project Installation

**Given**: Empty target directory
**When**: Run `./install.sh /path/to/target`
**Then**: `.agentic/` is copied, VERSION file created, success message shown

### Scenario 2: Profile Selection

**Given**: Installed framework
**When**: Agent runs init_playbook.md
**Then**: User is prompted to choose Discovery or Formal profile

### Scenario 3: Already Initialized

**Given**: Project with existing `.agentic/`
**When**: Run `./install.sh /path/to/target`
**Then**: Warning shown, installation does not overwrite
