# DEV-0199: Instruction File Sync Detection - Acceptance Criteria

**Feature**: Detect when ag.sh commands exist but instruction files haven't been updated.

---

## Acceptance Criteria

### instruction-sync.sh (P4a)

- [ ] **AC-001**: `.agentic/lib/tools/instruction-sync.sh` exists and is executable
- [ ] **AC-002**: Parses `ag.sh` case statement to discover subcommands
- [ ] **AC-003**: Checks each command appears in CLAUDE.md template
- [ ] **AC-004**: Checks each command appears in cursorrules.txt template
- [ ] **AC-005**: Checks each command appears in copilot-instructions.md template
- [ ] **AC-006**: Checks each command appears in codex-instructions.md template
- [ ] **AC-007**: Checks each command appears in auto_orchestration.md
- [ ] **AC-008**: Checks each command appears in memory-seed.md
- [ ] **AC-009**: Reports missing commands per file with clear output

### Validation Wiring (P4b)

- [ ] **AC-010**: instruction-sync check is wired into `validate_framework.sh` (warning mode)
- [ ] **AC-011**: `pre-commit-check.sh` warns if ag.sh changed but instruction files weren't modified in the same commit

---

## Non-Functional

- [ ] **NF-001**: Agent-agnostic — script works from any tool
- [ ] **NF-002**: `bash tests/validate_framework.sh` passes
