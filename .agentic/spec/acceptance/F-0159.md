# F-0159: Bootstrap & Thin Wrapper Mechanism — Acceptance Criteria

**Feature**: Auto-extraction of `lib/` from tarball with thin wrapper delegation pattern.

---

## Acceptance Criteria

### P1 — Bootstrap

- [x] **AC-001**: `bootstrap.sh` exits 0 immediately if `lib/tools/` already exists (no-op in framework repo)
- [x] **AC-002**: `bootstrap.sh` extracts from newest `agentic-lib-v*.tar.gz` in `.agentic/` if lib missing
- [x] **AC-003**: Extraction uses PID-namespaced temp dir (`$$.`) for atomic `mv`
- [x] **AC-004**: Fallback: downloads tarball from GitHub releases using version from STACK.md
- [x] **AC-005**: Version extraction uses macOS-compatible grep (no `-oP` Perl regex)
- [x] **AC-006**: Bootstrap fails with clear error if no tarball and no download available

### P1 — Thin Wrappers

- [x] **AC-007**: `.agentic/ag` runs bootstrap then delegates to `lib/tools/ag.sh`
- [x] **AC-008**: `.agentic/hooks/pre-commit` detects CI environments and skips
- [x] **AC-009**: `.agentic/hooks/pre-commit` reads `pre_commit_hook` setting from STACK.md (no/fast/full)
- [x] **AC-010**: `.agentic/hooks/pre-commit` runs spec validation for Formal profile
- [x] **AC-011**: `.agentic/hooks/pre-commit` delegates to `lib/hooks/pre-commit-check.sh` with `--mode`
- [x] **AC-012**: `.agentic/hooks/claude/*.sh` wrappers inline bootstrap then delegate to `lib/claude-hooks/`
- [x] **AC-013**: All wrappers fail open (exit 0) if bootstrap fails — never block user's work

## Tests

- `tests/validate_framework.sh` — structural checks for wrapper existence
- Manual: delete `lib/`, run `ag` → auto-restores from tarball
