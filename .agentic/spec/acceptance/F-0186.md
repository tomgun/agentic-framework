# F-0186: Autonomous Scheduler

**ADR**: ADR-001, Phase 7, Section 3
**Dependencies**: F-0182, F-0184

## Acceptance Criteria

- [ ] **AC-001**: `AutonomousScheduler` implements `get_unblocked() → spawn worker → review gate → repeat` loop
- [ ] **AC-002**: Non-blocking reviews: while one feature awaits human/escalated review, scheduler advances other unblocked features
- [ ] **AC-003**: Worker agents are scoped to components (uses component registry)
- [ ] **AC-004**: Evolves `crunch.py` into scheduler-backed execution (single rewrite, not layered)
- [ ] **AC-005**: `ag auto epic F-XXXX` command starts autonomous execution of an epic's child features
- [ ] **AC-006**: When critical agent escalates, scheduler logs escalation, creates HUMAN_NEEDED entry, and continues with other features
- [ ] **AC-007**: When all remaining features are blocked on human review, scheduler reports status and waits
- [ ] **AC-008**: When human resolves a review, scheduler picks up the feature again
- [ ] **AC-009**: Unit tests cover scheduling loop, non-blocking reviews, escalation handling, and component-scoped workers
