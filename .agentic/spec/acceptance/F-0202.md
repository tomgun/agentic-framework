# F-0202: Run Info (ag run) — Acceptance Criteria

## AC-001: ag run runs without error
`ag run` runs without error on a project with filled-in STACK.md.

## AC-002: Stack summary output
Output includes stack summary (language, framework, platform).

## AC-003: Dev server command
Output includes dev server command when detectable.

## AC-004: Build command
Output includes build command when detectable.

## AC-005: Test commands
Output includes test commands from STACK.md Testing section.

## AC-006: Unfilled STACK.md warnings
Output warns about unfilled STACK.md fields (template comments treated as "not configured").

## AC-007: Auto-detection fallback
Falls back to `discover.py` auto-detection when STACK.md is sparse.

## AC-008: run.sh exists and is executable
`run.sh` exists at `.agentic/lib/tools/run.sh` and is executable.

## AC-009: ag dispatch
`ag run` dispatch exists in `ag.sh`.

## AC-010: Tests pass
Tests pass in `validate_framework.sh` (T-0114 through T-0122).

## AC-011: Package manager awareness
Dev commands use correct package manager (pnpm/yarn/bun, not always npm).
