# F-0206: Feedback Capture System — Acceptance Criteria

## AC-001: Classify and persist feedback
`ag feedback "text"` classifies via keyword heuristics, persists to FEEDBACK_LOG.md with FB-XXXX ID.

## AC-002: Direct routing flags
`--bug` routes to ISSUES.md via quick_issue.sh; `--feature` routes to TODO.md via todo.sh.

## AC-003: AC adjustment reference
`--ac F-XXXX AC-XXX "text"` logs AC adjustment with feature/AC cross-reference.

## AC-004: Feedback log listing
`ag feedback log` shows entries; `--pending` filters to unrouted items only.

## AC-005: feedback_mode setting
`feedback_mode` setting exists in profiles.conf for all 3 profiles, resolved by get_setting.

## AC-006: Engine cleanup flushes feedback
Engine `_cleanup()` flushes in-flight `EngineState._feedback` to FEEDBACK_LOG.md via feedback.sh.

## AC-007: Fallback when engine not running
`ag auto feedback` falls back to `feedback.sh add` when engine is not running.

## AC-008: Instruction files updated
All instruction files updated: CLAUDE.md template, cursorrules, copilot, codex, memory-seed, auto_orchestration, agent_operating_guidelines.
