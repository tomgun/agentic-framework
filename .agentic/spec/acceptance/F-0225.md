# F-0225: Spec Evolution Metrics

## Acceptance Criteria

### Core Metrics (P1 — MVP)

- [x] **AC-001**: `spec-metrics.sh` counts `[Discovered]` markers per AC file; `spec-metrics.sh F-XXXX` shows single-feature discovery count; default mode shows all shipped features
- [x] **AC-002**: `spec-metrics.sh --churn` counts git log commits per AC file, bucketed into high (>10), medium (4-10), low (1-3); gracefully returns 0 when git is unavailable
- [x] **AC-003**: `ag audit --metrics` delegates to `spec-metrics.sh` and produces output; help text updated in both help blocks
- [x] **AC-004**: Retrospective checklist includes "Spec Evolution Review" section with items for running metrics, reviewing discovery patterns, reviewing high-churn specs, and process improvement

### Integration (P2 — Enhancement)

- [x] **AC-005**: `dashboard.sh` shows conditional `Spec evolution` line via `spec-metrics.sh --summary-line`; raw mode includes `===SPEC_METRICS===` section
- [x] **AC-006**: `spec-metrics.sh --json` outputs machine-readable JSON with per-feature discovery counts and churn data
