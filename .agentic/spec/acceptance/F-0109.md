# F-0109: Spec-Code Traceability Enhancements

## Overview
Enhance existing drift and coverage tools to answer key traceability questions reliably.

## Acceptance Criteria

### JSON Output (v0.1)
- [x] drift.sh supports `--json` flag for machine-readable output
- [x] coverage.py supports `--json` flag for machine-readable output
- [x] JSON includes timestamp, tool name, issues array, and summary
- [x] JSON is valid (parseable by standard JSON tools)

### Unified CLI (v0.1)
- [x] `ag trace` runs both drift and coverage checks
- [x] `ag trace --json` outputs combined JSON from both tools
- [x] `ag trace --gaps` shows only missing implementations
- [x] `ag trace --orphans` shows only orphaned code/annotations

### Reverse Lookup (v0.2)
- [x] `coverage.py --reverse FILE` shows what features a file implements
- [x] `ag trace FILE` calls reverse lookup
- [x] `ag trace F-XXXX` shows files implementing that feature

### Test-to-Feature Inference (v0.3)
- [x] `coverage.py --test-mapping` infers test→feature relationships
- [x] Explicit naming method: test_F0003_*.py → F-0003
- [x] Import tracing method: test imports annotated file
- [x] Output includes confidence level for each mapping
- [x] `ag trace --tests` shows test mapping

### Documentation
- [x] code_annotations.md updated with test inference conventions
- [x] Help text updated for all new options
- [x] ag.sh help includes trace command examples

## Questions Answered

| Question | How Answered |
|----------|--------------|
| What specs are not implemented? | `ag trace --gaps` / `coverage.py --json` |
| What code has no spec? | `drift.sh --json` (undocumented_code issues) |
| What's changed since sync? | `drift.sh --json` (stale_* issues) |
| Which tests validate which features? | `coverage.py --test-mapping` |
| What does this file implement? | `ag trace FILE` |
| What implements this feature? | `ag trace F-XXXX` |

## Non-Goals (Explicitly Excluded)
- AC-level granularity (too hard, low value)
- @verifies annotation (adds cognitive load, use convention instead)
- Staleness scoring (advisory warnings enough)
- Cached index (YAGNI - add only if perf problem)
