# F-0218: NFR Propagation Pipeline - Acceptance Criteria

**Feature**: Make NFR.md the living source of truth that actively propagates constraints into feature ACs, detects staleness, and captures informal invariants.

---

## Behavior (what the user needs — technology-agnostic)

When writing a feature spec, the agent runs a tool that auto-derives the NFR Constraints section instead of manually reading NFR.md. When NFR.md changes, affected features are flagged as stale. When someone says "it must always...", the agent can capture it as a structured NFR with a single tool invocation.

---

## Acceptance Criteria

### Propagation Tool (P1 — MVP)
**Verify independently**: Run `nfr-propagate.sh` in each mode against test fixtures

- [ ] **AC-001**: `nfr-propagate.sh derive F-XXXX` outputs a draft `### NFR Constraints` section using `nfr-applicable.sh`
- [ ] **AC-002**: Derive output includes one AC per applicable NFR with statement and threshold from NFR.md
- [ ] **AC-003**: `nfr-propagate.sh check --all` reports features with stale NFR references (NFR.md changed since AC written)
- [ ] **AC-004**: `nfr-propagate.sh sync F-XXXX` compares current AC NFR constraints vs derive output, flags missing/outdated/extra
- [ ] **AC-005**: Sync recognizes both `## NFR Compliance` (legacy) and `### NFR Constraints` (new) formats
- [ ] **AC-006**: Sync suggests running `nfr-migrate.sh` when legacy-format sections detected

### Capture Tool (P1 — MVP)
**Verify independently**: Run `nfr-capture.sh` with test statement

- [ ] **AC-007**: `nfr-capture.sh "statement"` assigns next NFR-XXXX ID and writes to NFR.md
- [ ] **AC-008**: Concurrency guard: checks `agents_helpers.py count-others`, logs to TODO.md if another agent active
- [ ] **AC-009**: Optionally runs `nfr-propagate.sh check` after capture to flag affected features

### Integration (P1 — MVP)
**Verify independently**: Run health check and implement workflow

- [ ] **AC-010**: `check-spec-health.sh --all` includes NFR staleness from `nfr-propagate.sh check` (exit code handled via `|| true`)
- [ ] **AC-011**: `check-spec-health.sh` dead code fixed: references `.agentic/lib/tools/nfr_validator.py` (not `spec/tools/`)
- [ ] **AC-012**: `ag implement` shows `nfr-propagate.sh sync` advisory when staleness detected

### Spec Writing Workflow (P1 — MVP)
**Verify independently**: Read spec_writing.md for consistency

- [ ] **AC-013**: `spec_writing.md` Step 2 replaced: uses `nfr-propagate.sh derive` instead of manual NFR matching

- [ ] **AC-015**: `spec_writing.md` NFR Integration section (lines 99-108) replaced with tool-based workflow
- [ ] **AC-016**: `acceptance.template.md` notes that `### NFR Constraints` is auto-populated by `nfr-propagate.sh derive`

## Out of Scope

- Blocking implementation on NFR staleness (advisory only)
- Automatic AC file modification (derive outputs text, agent inserts)
- NFR conflict detection
- Replacing `nfr-migrate.sh` (sync complements it — sync diagnoses, migrate fixes)
