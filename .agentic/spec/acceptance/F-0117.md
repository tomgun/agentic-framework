# F-0117: Spec Migration System

## Acceptance Criteria

- [x] `migration.sh create "title"` creates a new numbered migration file
- [x] `migration.sh create` auto-updates `_index.json` with new entry
- [x] `migration.sh list` shows all migrations with IDs and dates
- [x] `migration.sh show N` displays migration content
- [x] `migration.sh search "term"` finds migrations matching keyword
- [x] `migration.sh apply` generates FEATURES.md from migrations
- [x] Apply command parses Features Added/Modified/Deprecated sections
- [x] Apply command detects shipped status from acceptance criteria
- [x] Works with bash 3.x (macOS compatibility)
- [x] Tool handles missing `spec/migrations/` gracefully

## Test Commands

```bash
# Create migration
bash .agentic/tools/migration.sh create "Test migration"

# List migrations
bash .agentic/tools/migration.sh list

# Show specific migration
bash .agentic/tools/migration.sh show 1

# Search migrations
bash .agentic/tools/migration.sh search "ADR"

# Apply migrations
bash .agentic/tools/migration.sh apply
```
