# F-012: Documentation Drift Detection

## Acceptance Criteria

- [x] `drift.sh --docs` runs documentation drift detection
- [x] Detects recently changed code files (from git log or manifest)
- [x] Identifies documentation files that reference changed code
- [x] Flags docs that weren't updated when referenced code changed
- [x] Shows "potentially stale" vs "updated" documentation
- [x] `drift.sh --docs --manifest F-XXXX` checks against specific manifest
- [x] Falls back to git log when manifest doesn't exist
- [x] Advisory only - never blocks (returns exit code 0)
- [x] Shows helpful tip for STACK.md configuration
