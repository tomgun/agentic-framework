# F-0207: Project Documentation Lifecycle - Acceptance Criteria

**Feature**: Doc registry validation, coverage reporting, scaffolded creation, and enforcement gates
**Plan**: `.agentic/journal/plans/2026-03-11-F-0207-project-documentation-lifecycle-plan.md`

---

## Acceptance Criteria

### P1 — Core (MVP)

- [ ] **AC-001**: `docs.sh --validate` detects registered-but-missing docs (registry entry points to non-existent file) and existing-but-unregistered docs (`.md` files in the project not in the registry). Unregistered scan is broad: all `.md` files with sensible exclusions (framework internals, config/state, node_modules). Exit code non-zero when issues found.

- [ ] **AC-003**: `docs.sh --create <path> --type <type> --trigger <trigger>` creates a new doc from `doc_types.md` inline templates and auto-registers it in STACK.md `## Docs`. Idempotent (rejects duplicate path). Validates type against `doc_types.md` headings. Rejects if path already exists (unless `--force`).

- [ ] **AC-004**: Pre-commit check 19 in `pre-commit-check.sh` runs `docs.sh --validate` as advisory (warnings only, exit 0). Skipped when `docs_gate: off` or `_FAST_MODE=1`.

- [ ] **AC-005**: `ag done` runs `docs.sh --validate` alongside existing `drift.sh --docs` check. When `docs_gate: blocking`: both must pass. When `docs_gate: warning`: both run as advisory. When `docs_gate: off`: both skipped.

## Tests

### Test 1: Validate — registered-but-missing
**Given**: STACK.md registers `docs/nonexistent.md`
**When**: `docs.sh --validate` runs
**Then**: Output contains warning about missing file, exit code non-zero

### Test 2: Validate — existing-but-unregistered
**Given**: `docs/guide.md` exists but is not in STACK.md `## Docs`
**When**: `docs.sh --validate` runs
**Then**: Output contains warning about unregistered file, exit code non-zero

### Test 3: Validate — clean state
**Given**: All registry entries exist, no unregistered docs in scan scope
**When**: `docs.sh --validate` runs
**Then**: Exit code 0, no warnings

### Test 4: Validate — directory entries
**Given**: STACK.md registers `docs/adr/` (directory)
**When**: `docs.sh --validate` runs
**Then**: Checks directory exists (not file). Files inside `docs/adr/` are NOT flagged as unregistered.

### Test 5: Validate — exclusions
**Given**: `.agentic/lib/tools/ag.sh` exists (framework internal)
**When**: `docs.sh --validate` runs
**Then**: NOT flagged as unregistered (excluded by scan rules)

### Test 6: Create — happy path
**Given**: `docs/api-guide.md` does not exist
**When**: `docs.sh --create docs/api-guide.md --type architecture --trigger feature_done`
**Then**: File created with architecture template content. STACK.md has new `- doc:` entry.

### Test 7: Create — duplicate rejection
**Given**: `docs/api-guide.md` already registered in STACK.md
**When**: `docs.sh --create docs/api-guide.md --type architecture --trigger feature_done`
**Then**: Rejected with error (idempotent guard)

### Test 8: Create — invalid type
**When**: `docs.sh --create docs/foo.md --type invalid_type --trigger manual`
**Then**: Rejected with error listing valid types

### Test 9: Pre-commit — advisory fires
**Given**: `docs_gate: warning` in STACK.md, registry has issues
**When**: Pre-commit check 19 runs
**Then**: Warnings printed, commit proceeds (exit 0)

### Test 10: Pre-commit — skipped when off
**Given**: `docs_gate: off` in STACK.md
**When**: Pre-commit check 19 runs
**Then**: Check skipped entirely

### Test 11: ag done — blocking enforcement
**Given**: `docs_gate: blocking`, registry has missing file
**When**: `ag done F-XXXX` runs
**Then**: Blocked with error about registry validation failure
