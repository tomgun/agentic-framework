# F-0079: Issue/Bug Tracking - Acceptance Criteria

**Feature**: Formal issue tracking parallel to feature tracking

**Version**: 0.9.0

---

## Acceptance Criteria

### Template Exists

- [x] **AC-001**: `ISSUES.template.md` exists in `.agentic/spec/`
- [x] **AC-002**: Template has proper format version marker

### Issue Format

- [x] **AC-010**: Issues use I-#### ID format
- [x] **AC-011**: Status field: open, in_progress, fixed, wont_fix
- [x] **AC-012**: Priority field: critical, high, medium, low
- [x] **AC-013**: Severity field: blocker, major, minor, cosmetic
- [x] **AC-014**: Found/Fixed date fields
- [x] **AC-015**: Steps to reproduce section
- [x] **AC-016**: Related features/commits section

### Integration

- [x] **AC-020**: Scaffold creates spec/ISSUES.md for Formal
- [x] **AC-021**: EMERGENCY.md documents issue logging
- [x] **AC-022**: quick_issue.sh creates properly formatted issues

### Sections

- [x] **AC-030**: Template has "Open Issues" section
- [x] **AC-031**: Template has "In Progress" section
- [x] **AC-032**: Template has "Recently Fixed" section
- [x] **AC-033**: Template has summary table with counts

## Validation Commands

```bash
# Check template exists
test -f .agentic/spec/ISSUES.template.md && echo "✓ ISSUES template exists"

# Check scaffold includes ISSUES.md
grep -q "ISSUES.template.md" .agentic/init/scaffold.sh && echo "✓ Scaffold includes ISSUES"

# Check format
grep -q "I-XXXX" .agentic/spec/ISSUES.template.md && echo "✓ Has I-#### format"
grep -q "Open Issues" .agentic/spec/ISSUES.template.md && echo "✓ Has Open Issues section"
```
