# F-0158: Central Path Resolution — Acceptance Criteria

**Feature**: `paths.sh` and `paths.py` as single source of truth for all framework paths.

---

## Acceptance Criteria

### P1 — Core Resolution

- [x] **AC-001**: `paths.sh` resolves `AGENTIC_LIB`, `AGENTIC_ROOT`, `PROJECT_ROOT` from its own location
- [x] **AC-002**: `PROJECT_ROOT` allows override via `ROOT_DIR` or `CLAUDE_PROJECT_DIR` environment variables
- [x] **AC-003**: `_resolve_path(new, legacy)` returns new path if it exists, falls back to legacy, defaults to new
- [x] **AC-004**: Double-source guard (`_AGENTIC_PATHS_LOADED`) prevents re-initialization
- [x] **AC-005**: All tracking file variables (`STATUS_FILE`, `TODO_FILE`, etc.) resolve correctly
- [x] **AC-006**: All journal variables (`JOURNAL_DIR`, `JOURNAL_FILE`, `PLANS_DIR`, etc.) resolve correctly
- [x] **AC-007**: All spec variables (`SPEC_DIR`, `FEATURES_FILE`, `ACCEPTANCE_DIR`, etc.) resolve correctly
- [x] **AC-008**: All session variables (`SESSION_DIR`, `WIP_FILE`, `AGENTS_ACTIVE_FILE`, etc.) resolve correctly
- [x] **AC-009**: All lib directory variables (`TOOLS_DIR`, `WORKFLOWS_DIR`, etc.) resolve correctly

### P1 — Migration

- [x] **AC-010**: ~50 shell scripts migrated from hardcoded paths to `source paths.sh`
- [x] **AC-011**: `paths.py` mirrors `paths.sh` structure for Python tools
- [x] **AC-012**: `ROOT_DIR`, `PROJECT_ROOT`, `AGENTIC_ROOT`, `AGENTIC_LIB` exported for downstream scripts

## Tests

- `tests/test_paths.sh` — 42 tests covering all variables, backward compat, edge cases
