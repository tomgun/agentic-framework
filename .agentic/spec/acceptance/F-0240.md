# F-0240: Framework Execution Log — Acceptance Criteria

## P1 (blocking)

- [ ] **AC-1**: `fwlog.sh` provides `flog()` — calling it appends a pipe-delimited line to `framework.log`
- [ ] **AC-2**: Every `ag <cmd>` produces start + end log entries (via EXIT trap in ag.sh)
- [ ] **AC-3**: Pre-commit produces start + end log entries (via EXIT trap)
- [ ] **AC-4**: Fail-open — unwritable log path doesn't crash any script
- [ ] **AC-5**: Log is gitignored (`.agentic/session/framework.log` and `.prev`)
- [ ] **AC-6**: F-0242-parseable format — `split('|')` on each line extracts 5 structured fields

## P2 (should have)

- [ ] **AC-7**: Session rotation — `SessionStart.sh` rotates `framework.log` to `framework.log.prev`
- [ ] **AC-8**: All 5 Claude hooks (`SessionStart`, `Stop`, `PostToolUse`, `UserPromptSubmit`, `PreCompact`) log fire events
- [ ] **AC-9**: `FRAMEWORK_LOG` defined in both `paths.sh` and `paths.py`
