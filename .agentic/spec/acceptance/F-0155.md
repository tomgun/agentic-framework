# F-0155: Unregistered Shipped Code Detection — Acceptance Criteria

**Feature**: Sync detects commits that look like unregistered features (no F-#### reference).

---

## Acceptance Criteria

- [x] **AC-001**: Commits with F-#### in message are not flagged
- [x] **AC-002**: Commits touching 3+ source files with 1+ new file and no F-#### are flagged
- [x] **AC-003**: Commits touching fewer than 3 source files are not flagged
- [x] **AC-004**: Commits modifying files without adding new ones are not flagged
- [x] **AC-005**: Test/doc/config directories are excluded from source file count
- [x] **AC-006**: .agentic/ files are excluded from source file count
- [x] **AC-007**: Merge commits are skipped
- [x] **AC-008**: Detection only runs when feature_tracking=yes
- [x] **AC-009**: Quiet mode feeds into ISSUE_SUMMARY for ag start probe
- [x] **AC-010**: Full mode shows commit hash, file counts, and message
