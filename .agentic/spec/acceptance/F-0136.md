# F-0136: Centralized TODO Tracking - Acceptance Criteria

**Feature**: Durable, git-tracked inbox for quick-capture of ideas, tasks, and reminders

---

## Acceptance Criteria

### TODO.md Template & Script

- [ ] **AC-001**: `TODO.template.md` exists in `.agentic/spec/`
- [ ] **AC-002**: `todo.sh` exists in `.agentic/tools/` and is executable
- [ ] **AC-003**: `todo.sh add "desc"` appends T-#### entry to Inbox section (single-write, no double-write)
- [ ] **AC-004**: `todo.sh done T-0001 "reason"` moves item from Inbox to Done with "Resolved:" note
- [ ] **AC-005**: `todo.sh drop T-0001 "reason"` moves item from Inbox to Done with "Dropped:" note
- [ ] **AC-006**: `todo.sh triage T-0001 feature "notes"` moves item to Done with "Promoted to" note
- [ ] **AC-007**: `todo.sh list` prints only Inbox items (section-aware, excludes Done)
- [ ] **AC-008**: Auto-generates T-#### IDs (sequential)

### ag.sh Integration

- [ ] **AC-010**: `ag todo "desc"` works as alias for `todo.sh add`
- [ ] **AC-011**: `ag todo list` / `ag todo done` / `ag todo drop` / `ag todo triage` all delegate correctly
- [ ] **AC-012**: `ag start` dashboard shows TODO inbox count
- [ ] **AC-013**: `ag help` includes `todo` command in both Discovery and Formal help text

### Scaffold & Dogfooding

- [ ] **AC-020**: `scaffold.sh` creates TODO.md for both Discovery and Formal profiles
- [ ] **AC-021**: Framework's own TODO.md exists at project root, seeded with backlog items

### Routing Rules

- [ ] **AC-030**: CLAUDE.md (framework + template) has trigger row for idea/todo/remember
- [ ] **AC-031**: CLAUDE.md has routing rule: task → `ag todo`, blocker → `blocker.sh`
- [ ] **AC-032**: memory-seed.md has todo trigger and routing rules
- [ ] **AC-033**: All 5 instruction files (claude, codex, copilot, cursor, framework) have todo trigger

### Structural Tests

- [ ] **AC-040**: S07 test checks todo/idea trigger in both memory-seed and CLAUDE.md template
- [ ] **AC-041**: S07 test checks todo.sh script reference in both memory-seed and CLAUDE.md template
- [ ] **AC-042**: S07 passes 24/24

### STATUS.md Cleanup

- [ ] **AC-050**: STATUS.template.md has no Backlog section
- [ ] **AC-051**: Framework STATUS.md Backlog items moved to TODO.md
