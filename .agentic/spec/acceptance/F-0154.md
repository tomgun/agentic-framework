# F-0154: SKIP_COMPLEXITY Per-File Warnings — Acceptance Criteria

**Feature**: When SKIP_COMPLEXITY is set, pre-commit still shows per-file details instead of silent skip.

---

## Acceptance Criteria

- [x] **AC-001**: When SKIP_COMPLEXITY is set, pre-commit scans staged files for length violations
- [x] **AC-002**: Over-limit files show filename, line count, and configured limit
- [x] **AC-003**: Framework-owned files (.agentic/*) are excluded from scanning
- [x] **AC-004**: Code extensions are read from STACK.md if configured
- [x] **AC-005**: When no files are over the limit, shows "(No staged files currently over the limit)"
- [x] **AC-006**: When files are over-limit, suggests `ag todo` or split before next commit
