# Plan: DEV-0243 — Complexity Tier Experiments

## Context

DEV-0243 is Part 3 of the QA Observatory epic. It adds an empirical experiment harness to compare what framework users get from three real configuration profiles: discovery, formal, and autonomous_formal. Dependencies F-0240 (fwlog.sh) and F-0242 (PhaseChecker) are already shipped.

**Core question**: Does framework ceremony (spec, plan review, gates) produce measurably better outcomes? What does each tier cost in time and what does it buy in quality?

## What Already Exists (Reuse)

- `setup_project(scenario, vw_path, project_dir, settings)` in `framework_verify.py` — scaffolds test projects with profile-correct STACK.md
- `spawn_claude(...)`, `build_prompt(...)`, `load_scenario(...)`, `PhaseChecker` — all importable from `auto.framework_verify`
- `spawn_claude`, `SpawnResult`, `discover_jsonl` — importable from `auto.__init__`
- `SCENARIOS_DIR`, `todo_app.yaml` — scenario already has discovery + autonomous_formal in settings_matrix

## Revision 2 Changes (from dialectical review)

**Dropped**: VW worktree — unnecessary for tier experiments. FrameworkVerifier needs a VW so fix agents can commit to an ephemeral branch. Tier experiments only READ the framework (to copy it) — so `project_root` is passed directly to `setup_project` as the copy source. Eliminates `_create_tier_vw`, `_cleanup_tier_vw`, `AG_TRUNK_BRANCH` env var, and all associated collision risks.

**Added to formal tier**: `review_plan: critical_agent` and `review_commit: critical_agent` — formal profile defaults these to `human`, which deadlocks autonomous experiments. Document as intentional: in experiments all tiers must complete autonomously.

**Metrics corrections**:
- `tests_pass`: run pip install in a separate step before pytest (pip failure should not mask test results)
- `total_commits`: subtract 1 for the init scaffold commit (`max(0, count - 1)`)
- `conventional_commits_pct`: exclude init commit from git log (`HEAD~1..HEAD` range, or `--skip=1`)
- `ac_completeness_pct`: guard zero features case with `max(total_features, 1)`

**Added**: Write results to `.agentic/session/tier-exp-results-<timestamp>.json` after experiment completes (5 lines, high value for 6-9hr run recovery)

**Documented**: All 3 tiers use the discovery prompt template (agent discovers workflow from STACK.md settings). This is intentional — we test what real users experience with each profile, not artificially instructed behavior. The `prompt_tier` field is NOT set in the experiment YAML.

## Architecture Decision: Standalone Module, Not FrameworkVerifier Subclass

`FrameworkVerifier` has self-healing logic (repair agents, PR creation) that is wrong for experiments. Experiments observe outcomes, not fix them. `tier_experiment.py` imports lower-level helpers directly (`setup_project`, `spawn_claude`, `build_prompt`) without subclassing.

**No VW worktree needed**: Pass `project_root` as the `vw_path` argument to `setup_project`. The function only uses `vw_path` to copy `.agentic/` into the temp project dir — `project_root / ".agentic"` is the correct source.

### 3. `.agentic/lib/auto/tier_experiment.py`

**TierMetrics dataclass**:
```python
@dataclass
class TierMetrics:
    # Identity
    tier: str
    scenario: str
    run_number: int

    # Universal (cross-tier comparison)
    app_runs: bool = False
    tests_pass: bool = False
    test_count: int = 0
    code_quality_errors: int = 0
    wall_time_seconds: float = 0.0
    total_commits: int = 0
    code_files_count: int = 0

    # Framework-specific
    spec_created: bool = False
    plan_created: bool = False
    plan_reviewed: bool = False
    journal_updated: bool = False
    conventional_commits_pct: float = 0.0
    features_shipped: int = 0
    ac_completeness_pct: float = 0.0
    framework_log_events: int = 0
    violations: list[dict] = field(default_factory=list)

    # Provenance
    timed_out: bool = False
    agent_exit_code: int = 0
    error: str = ""
```

**ExperimentResult dataclass**:
```python
@dataclass
class ExperimentResult:
    experiment_name: str
    runs: list[TierMetrics] = field(default_factory=list)

    def by_tier(self) -> dict[str, list[TierMetrics]]: ...  # group by tier
    def to_dict(self) -> dict: ...  # JSON-serializable
```

**collect_metrics(project_root, run_start_time, jsonl_log_path, tier_name, scenario_name, run_number, spawn_result, test_command)** — best-effort collection:
- `app_runs`: run pip install step first (`pip install -q -r requirements.txt`), check returncode; if 0, then run tests
- `tests_pass`: run `pytest` (or test runner from scenario) separately from pip install; returns False if pip install failed
- `test_count`: grep `^def test_` in `tests/**/*.py` via Python regex
- `code_quality_errors`: `shutil.which("ruff")` → run ruff check, count lines; else 0
- `wall_time_seconds`: `time.time() - run_start_time`
- `total_commits`: `git rev-list --count HEAD`, subtract 1 for init scaffold commit → `max(0, count - 1)`
- `code_files_count`: `rglob("*.py")` excluding `.git` and `.agentic`
- `spec_created`: `.agentic/spec/acceptance/` has *.md OR `.agentic/spec/contracts/` has *.yaml
- `plan_created`: `.agentic/journal/plans/` has *-plan.md
- `plan_reviewed`: plan file contains `**Status**: APPROVED`
- `journal_updated`: JOURNAL.md contains `### Session:`
- `conventional_commits_pct`: `git log --format=%s --skip=1` (skip init commit), count lines matching `^(feat|fix|chore|docs|test|refactor|style|perf|ci|build)[\(:]` / total (guard: `max(total_lines, 1)`)
- `features_shipped`: grep `**Status**: shipped` count in FEATURES.md
- `ac_completeness_pct`: F-XXXX IDs in FEATURES.md that have AC/contract files / total features; guard `max(total_features, 1)` for zero-features case
- `framework_log_events`: count valid pipe-delimited lines in `.agentic/session/framework.log`
- `violations`: lazy-load `session-analyze.py` via importlib, call `detect_violations(extract_events(parse_jsonl(jsonl_path)))`; return `[]` if JSONL absent or any error

**No VW worktree.** `setup_project` takes `vw_path` only to copy `.agentic/` from it. Pass `project_root` directly:

```python
setup_project(scenario, project_root, temp_dir, tier_settings)
# setup_project does: shutil.copytree(project_root / ".agentic", temp_dir / ".agentic")
```

No `_create_tier_vw`, no `AG_TRUNK_BRANCH` env var. This eliminates all env-var pollution and collision risks.

**run_experiment(experiment_config, project_root, ...)** orchestrator:
- Pre-flight: check `FRAMEWORK_DEVELOPMENT.md` present (framework-only guard), check claude_command exists
- For each tier × scenario × rep:
  1. `temp_dir = Path(tempfile.mkdtemp(...))`
  2. `setup_project(scenario, project_root, temp_dir, tier_settings)`
  3. `spawn_claude(claude_cmd, temp_dir, prompt, timeout, log_file, monitor=True)`
  4. `collect_metrics(...)` on completed project
  5. `shutil.rmtree(temp_dir)` in finally block
- After all runs: write `result.to_dict()` to `.agentic/session/tier-exp-results-<timestamp>.json`

**CLI**:
```
tier_experiment.py --project-root . --experiment complexity_tiers [--json] [--dry-run] [--single-run]
```
`--single-run`: 1 rep per tier (development mode)
`--dry-run`: print planned runs, no agents spawned

**`_print_comparison(result)`**:
- Cross-tier table of universal metrics (mean ± range across reps)
- Per-tier breakdown of framework-specific metrics
- Violation summary
- Note: "n=3 provides directional signal only; per-run values shown"

**`_print_dry_run(config, single_run)`**:
- Print total runs, tiers, scenarios, per-run details

## Key Design Decisions

1. **No changes to `framework_verify.py`** — it already exports what's needed
2. **`formal` tier uses `review_merge: skip`** — required for autonomous completion in experiments
3. **`_load_yaml` replicated inline** — don't import private `_load_yaml` from framework_verify
4. **Lazy session-analyze import** — same `importlib` pattern as framework_verify.py
5. **Best-effort metrics** — missing tools/logs → default values, not exceptions
6. **VW prefix `tier-exp/run-*`** — doesn't collide with `verify/run-*` branches

## Risks

| Risk | Severity | Mitigation |
|------|----------|------------|
| 9 full runs expensive (time + cost) | HIGH | `--single-run` for dev; `--dry-run` for validation |
| formal/autonomous_formal timeout at 2hrs | MEDIUM | Default timeout in YAML, override via `--single-run` |
| Missing JSONL → no violations metric | LOW | Graceful default to `[]` |
| ruff not installed | LOW | `shutil.which` check, default to 0 |
