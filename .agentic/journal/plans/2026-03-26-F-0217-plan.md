# Plan: Structural Doc Update Enforcement

## Context

Doc updates keep getting skipped when features ship. Every enforcement point is advisory — agents skip them. This session alone: F-0217, F-0218, F-0219 all shipped without doc updates until the user manually asked. The root cause is architectural: doc updates are reactive (triggered after done) not structural (blocking before done). The existing `docs_gate: blocking` setting has no teeth — it fires a human prompt that autonomous pipelines skip (`! -t 0` escape), and `drift.sh` exit codes are swallowed with `|| true`.

## Approach: Add teeth to existing infrastructure

Three structural changes, plus skill updates for behavioral guidance:

### 1. `docs.sh --check-freshness` — New deterministic freshness check

**File**: `.agentic/lib/tools/docs.sh`

Add `check_freshness()` function that:
- Parses STACK.md `## Docs` registry for `feature_done`-triggered entries
- For each registered doc, checks if modified in current branch (`git diff main...HEAD`) or recent commits
- Returns exit 0 if all fresh, exit 1 with stale list if not
- CLI: `docs.sh --check-freshness [--trigger feature_done]`

Freshness logic (deterministic, git-based — no heuristics):
- File doesn't exist → STALE
- File in `git diff main...HEAD` → FRESH
- File modified in last 5 commits → FRESH
- Otherwise → STALE

### 2. `ag.sh` cmd_done — Replace advisory prompt with `done_failures` gate

**File**: `.agentic/lib/tools/ag.sh` (lines ~1549-1592)

Replace the current doc drift section with a structural gate:
- Remove `! -t 0` escape (autonomous and interactive treated identically)
- Call `docs.sh --check-freshness`
- If stale + `docs_gate: blocking` → increment `done_failures` (hard exit 1)
- If stale + `docs_gate: warning` → warn only
- `docs_mode: deferred` → skip freshness but still check registry health (missing files = always an error)
- Remove `|| true` from drift.sh call

### 3. Pre-commit Check 19 — Make it blocking when `docs_gate: blocking`

**File**: `.agentic/lib/hooks/pre-commit-check.sh` (lines ~1057-1078)

Only for registered-but-missing files (not freshness — too expensive at commit time):
- `docs_gate: off` → skip
- `docs_gate: warning` → advisory (current)
- `docs_gate: blocking` → increment FAILURES

### 4. Skills — Add doc verification steps

**Files** (4 files, root + template pairs):
- `completing-work/SKILL.md`: Add Step 5b — run `docs.sh --check-freshness` before `ag done`
- `implementing-features/SKILL.md`: Add doc check to Step 6 verification list

### 5. Tests

**File**: `tests/test_docs_freshness.sh` (new)
- Recently committed doc → exit 0
- Stale doc → exit 1 with list
- No feature_done docs → exit 0
- Missing registered doc → exit 1

## What this does NOT change

- `docs.sh --trigger` still fires (assembles drafting context)
- `drift.sh --docs` remains advisory for heuristic detection
- `docs_mode: deferred` remains valid — suppresses freshness blocking but not registry health
- Discovery profile unaffected (`docs_gate: off` by default)
