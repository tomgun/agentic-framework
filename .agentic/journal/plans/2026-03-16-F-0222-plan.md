# F-0222: State Machine Enforcement = Blocking

## Context

The framework's state machine controls feature lifecycle transitions with gates checking preconditions (AC file exists, tests exist, etc.). Currently gate failures are always **advisory** — they warn but allow transitions. F-0222 makes gate failures **blocking** for formal profiles.

**The wiring gap**: `ag.sh` reads `state_enforcement` from STACK.md and has `if [ "$enforcement" = "blocking" ]` branches with `exit 1`. But it never passes `--enforce` to `state_machine.py`, so the Python process always runs in advisory mode (exit 0), and the shell's blocking branches are dead code.

**Status**: APPROVED

**File: `.agentic/lib/tools/ag.sh`**
