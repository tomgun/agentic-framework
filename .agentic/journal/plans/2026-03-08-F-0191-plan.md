# Plan: Merge Dialectical Review INTO Plan-Review Loop

## Context

The initial implementation created dialectical review (F-0191) as a separate Step 5.5 after the plan-review loop (F-0120). User direction: these are the SAME thing. The dialectical approach (critic + advocate, fresh context, user decides) IS how plan review works. It should support iteration.

The problem with the old model: a single reviewer's word is treated as truth. If the reviewer says REVISION_NEEDED, the planner revises without questioning whether the criticism was valid. The dialectical approach fixes this — no one agent has authority, the user sees a debate.

## Design decisions

### Iteration mechanics
1. After synthesis, user chooses: **Proceed**, **Revise**, or **Reject**
2. If Revise: user tells Planner what to change (guided by synthesis's "Revision Guidance" section)
3. Planner revises the plan artifact, increments iteration counter
4. Fresh Critic + Advocate run on the revised plan (new iteration)
5. At `plan_review_max_iterations`, suggest human escalation (advisory, not blocking)
6. Plan artifact status stays `REVIEWING` during iteration, user sets `APPROVED` when proceeding

### Synthesis gets "Revision Guidance" section
To give the Planner actionable direction without verdicts:
```
## Revision Guidance (if user chooses to revise)
1. [Most critical — from High-Confidence Findings]
2. [Important — from Uncontested Critic Concerns]
3. [Consider — from Points of Contention where Critic has stronger case]
```

### plan-reviewer-agent.md → deprecated
The Critic now covers the adversarial review role. The old plan-reviewer-agent becomes dead code. Mark as deprecated with pointer to plan-critic-agent.md (don't delete — existing plans reference it).

### Two workflow files → clear relationship
- `plan_review_loop.md` = orchestration (full lifecycle: creation, iteration, escalation, approval)
- `dialectical_review.md` = mechanism (how each review round works: critic+advocate+synthesis)
- `plan_review_loop.md` references `dialectical_review.md` for the review mechanism

### Cost acknowledgment
Fresh context per iteration = 2 agents × N iterations. More expensive than old single-reviewer model. Worth it: independence catches groupthink. Mid-tier models keep costs reasonable.
