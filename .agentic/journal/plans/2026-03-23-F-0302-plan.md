# F-0302 Phase 4 Step 4.2: User Input Automation

## Context

The YAML contract system (shipped in Phase 3) includes a `user_input` field on every contract — a communication channel where users write change requests. The detection infrastructure exists (`contracts.py` has `get_pending_user_input()`, `ag contract pending` works), but nothing surfaces pending input to agents or guides them through processing it. This step wires detection into agent-facing surfaces and defines the processing workflow.

## Design Decisions

1. **No new commands** — reuse `ag contract pending`, `ag contract set`, `ag contract add-migration`
2. **INFO not BLOCK** — `ag implement` shows pending user_input as guidance, not a gate (the user WANTS the agent to process it)
3. **user_input field exempt from migration** — it's a communication channel, not spec content. Pre-commit Check 23 must skip migration requirement when only `user_input` changed
4. **Single Python call** — dashboard uses one `get_pending_user_input()` call, not N calls per contract

## Implementation Steps

### Step 1: Pre-commit user_input exemption (enables the workflow)

**File**: `.agentic/lib/hooks/pre-commit-check.sh` (lines 1310-1313)

Between the `IS_PROTECTED == yes` check (line 1310) and the migration check (line 1313), add a Python snippet that compares staged vs HEAD versions of the contract with `user_input` stripped. If they're identical after stripping, only `user_input` changed — skip migration requirement.

```bash
      if [[ "$IS_PROTECTED" == "yes" ]]; then
        CID=$(basename "$contract_file" .yaml)
        # Exempt user_input-only changes from migration requirement
        ONLY_UI=$(PYTHONPATH="$ROOT_DIR/.agentic/lib" python3 -c "
import yaml, subprocess, sys
s = yaml.safe_load(subprocess.run(['git', 'show', ':$contract_file'], capture_output=True, text=True).stdout or '{}')
h = yaml.safe_load(subprocess.run(['git', 'show', 'HEAD:$contract_file'], capture_output=True, text=True).stdout or '{}')
s.pop('user_input', None); h.pop('user_input', None)
print('yes' if s == h else 'no')
" 2>/dev/null || echo "no")
        if [[ "$ONLY_UI" == "yes" ]]; then
          echo "  ℹ $CID: only user_input changed (exempt from migration)"
          continue
        fi
        # existing migration check follows...
```
