# Fix Migration 008 Stub + Surface Spec Protection in Docs

## Context

Migration 008 was created during the F-0168 shipping process to satisfy Check 14 (shipped spec protection), but `migration.sh create` only generates a template stub. The migration file needs actual content describing what changed.

Additionally, an audit revealed that spec protection — one of the framework's key safety mechanisms — is well-documented in deep reference files (`spec_writing.md`, `spec_protection.md`, `spec_migrations.md`) but invisible in the entry points agents actually read first (`CLAUDE.md`, `CLAUDE.template.md`, `FRAMEWORK_QUICK_START.md`, `agent_operating_guidelines.md`). Agents only discover spec protection when pre-commit Check 14 blocks them — too late.
