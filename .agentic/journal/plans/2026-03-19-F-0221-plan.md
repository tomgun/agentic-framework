# F-0221: ag.sh Decomposition — Implementation Plan

**Status**: APPROVED

**Review**: Dialectical review (Critic+Advocate, 2026-03-19). Critic flagged validate_framework.sh greps that search ag.sh for function content — must update those checks in each phase (not deferred to Phase 4). Advocate confirmed source pattern, module boundaries, and cross-module call safety. Converged — no design changes needed.

## Context

`ag.sh` is 4,325 lines with 58 functions — the CLI gateway for the entire framework. It's maintainable-enough today but growing. This decomposition extracts command functions into sourced modules under `commands/`, leaving ag.sh as a thin dispatcher (~300 lines). All behavior is preserved — no user-facing changes.

## Approach

**Source pattern**: ag.sh sources module files → all functions share global scope → cross-command calls (merge→done, done→verify) work naturally → existing tests work with minimal changes.

**Module directory**: `.agentic/lib/tools/commands/`

**Module template** (each file):
```bash
#!/usr/bin/env bash
# commands/<name>.sh — <description>
# Sourced by ag.sh — do NOT execute directly.
# Depends on: SCRIPT_DIR, ROOT_DIR, PROFILE, color codes, paths.sh, settings.sh

<function definitions — cut/paste from ag.sh, no modifications>
```

Modules must NOT redefine SCRIPT_DIR, ROOT_DIR, call `set`, or re-source shared libs.

## Risks & Mitigations

| Risk | Mitigation |
|------|-----------|
| test_ag_gateway.sh breaks (copies ag.sh to temp dir) | Fix setup_test_env in Phase 1 to also copy commands/ |
| settings.sh name collision (lib/settings.sh vs commands/settings.sh) | Different paths, no collision — source uses full path |
| SCRIPT_DIR wrong in modules | Modules inherit from ag.sh, never redefine — verified no BASH_SOURCE in functions |
| Cross-module function calls | All sourced before dispatch; bash resolves at call time |
| Phase too large for NFR-0003 | Each phase: 4-8 files, all under 10 |
