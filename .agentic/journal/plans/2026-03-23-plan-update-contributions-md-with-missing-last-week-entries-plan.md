### 2. F-0301 — Feature Status Audit + Completion Gate (PR #191+192, v0.71.0)
- **User insight**: Conducted systematic feature status audit; found 3 features (F-0240, F-0242, F-0194) with merged code on main but still marked "planned" — agents had committed directly to main bypassing `ag done`
- **Design direction**: `ag implement` should structurally block when any prior backlog item has merged code but isn't shipped — passive detection on dashboard + advisory on ag start
- **Source**: Journal session 2026-03-22 10:08 "8 features had merged code but stale planned status"

### 3. Scaffold-First Hook Architecture (PR #190, v0.71.0)
- **User insight**: Scaffold already pre-installs hooks to `lib/` — the wrapper layer in `.agentic/hooks/claude/` was redundant. Init playbook was reinstalling them mid-session, causing misleading "Claude Code restart required" warnings that confused users
- **Design direction**: Eliminate 9 wrapper scripts. `hooks.json` points directly to `lib/claude-hooks/` — hooks auto-update with framework upgrades instead of requiring manual wrapper sync. Init playbook Step 1a rewritten from "install" to "verify/prune." Init interview uses `AskUserQuestion` for batched questions rather than 7 sequential prompts
- **Source**: Journal session 2026-03-22 09:04 "Hooks were already pre-installed by scaffold but init playbook redundantly reinstalled them"

### 4. F-0302 Phase 4 — User Input as Agent Control Surface (PR #196, v0.73.0)
- **User insight**: The `user_input` field in contracts (a key design principle: specs as control interface) is only useful if agents can *discover* it — a field buried in a YAML file nobody reads is not a control surface. The discovery pipeline was missing entirely: agents had no way to know pending input existed
- **Design direction**: Surface user_input at every entry point: dashboard shows "📥 N pending", `ag start` shows previews, `ag implement` shows INFO guidance. New skill `handling-contract-input` defines the response workflow (7 steps: discover → read → test → implement → migrate → clear → verify). Trigger words added to all 7 instruction files
- **Source**: Journal session 2026-03-23 07:21 "Pending user_input on contracts had no agent-facing surface"
