## Free-to-Use Media Sources

### Images & Photos

#### **Tier 1: Free, No Attribution Required**

1. **Unsplash** (https://unsplash.com)
   - 4M+ high-quality photos
   - License: Free for commercial use, no attribution required
   - Use case: Product photos, backgrounds, hero images
   - API: Yes (for programmatic access)

2. **Pexels** (https://pexels.com)
   - 3M+ photos and videos
   - License: Free, no attribution (Pexels License)
   - Use case: Stock photos, marketing images
   - API: Yes

3. **Pixabay** (https://pixabay.com)
   - 4.4M+ photos, vectors, illustrations
   - License: Free for commercial use (Pixabay License)
   - Use case: Diverse image needs
   - API: Yes

#### **Tier 2: Free with Attribution**

4. **Wikimedia Commons** (https://commons.wikimedia.org)
   - 100M+ media files
   - License: Varies (CC-BY, CC-BY-SA, Public Domain)
   - Use case: Historical images, diagrams, educational content
   - Note: CHECK LICENSE PER IMAGE

5. **Flickr Creative Commons** (https://flickr.com/creativecommons)
   - Millions of CC-licensed photos
   - License: Varies by image (CC-BY, CC-BY-SA, etc.)
   - Use case: Diverse photography
   - Note: ALWAYS CHECK LICENSE

## AI-Generated Media Assets

### AI Image Generation

1. **Stable Diffusion (Free, Open Source)**
   - Run locally or via free services (Hugging Face Spaces)
   - License: Generated images are yours
   - Use case: Custom illustrations, concept art
   - Quality: Excellent
   - Note: Requires GPU for local, or use online for free

2. **DALL-E 3 (via ChatGPT Plus / Bing Image Creator)**
   - Bing Image Creator: FREE (with limits)
   - ChatGPT Plus: $20/mo (includes DALL-E 3)
   - License: Generated images are yours
   - Use case: High-quality custom images

3. **Midjourney** (Paid, but trial available)
   - $10/mo basic plan
   - License: Commercial use allowed (check terms)
   - Quality: Excellent

### AI Sprite & Pixel Art Generation

1. **Stable Diffusion with PixelArt LoRA** (Free)
   - Use Stable Diffusion + pixel art model
   - License: Generated images are yours
   - Use case: Game sprites

2. **Aseprite** (Paid $20, but can compile from source free)
   - Not AI, but excellent for sprite creation
   - License: Proprietary (but fair)

### AI Sound Effect Generation

1. **Riffusion** (Free, Open Source)
   - Generate music from text prompts
   - License: Open source (MIT)
   - Use case: Ambient music, soundscapes
   - Quality: Experimental

2. **AudioCraft (Meta)** (Free, Open Source)
   - Generate sound effects and music from text
   - License: Open source
   - Quality: Good for SFX

3. **Mubert AI** (Free tier available)
   - Generate royalty-free music
   - License: Check per plan
   - Use case: Background music

## Agent Workflow for Media Assets

### When Agent Needs an Asset

**Agent should**:

1. **Check if asset already exists**:
   - Look in `assets/images/`, `assets/audio/`, etc.
   - Check `assets/ATTRIBUTION.md` for existing assets

2. **If asset doesn't exist, ask human**:
   ```
   "I need [description] for [feature].
   
   Options:
   a) Source from free library (I'll find it on Unsplash/Kenney/Freesound)
   b) Generate with AI (I'll create a prompt for Stable Diffusion/AudioCraft)
   c) Use placeholder for now (add to HUMAN_NEEDED.md)
   d) You'll provide it
   
   Which would you prefer?"
   ```

3. **If human chooses (a), agent provides specific links**:
   ```
   "For [hero background image], I recommend:
   - Unsplash: https://unsplash.com/photos/ABC123 (no attribution needed)
   - Download: 1920x1080, save to assets/images/hero-bg.jpg
   - I'll add it to ATTRIBUTION.md"
   ```

4. **If human chooses (b), agent provides generation prompt**:
   ```
   "For [fantasy forest sprite], here's the Stable Diffusion prompt:
   
   'pixel art sprite, 32x32, fantasy forest tree, isometric view,
   green foliage, brown trunk, game asset, transparent background,
   clear outlines'
   
   Generate at: https://huggingface.co/spaces/stabilityai/stable-diffusion
   Save to: assets/sprites/tree-forest-01.png"
   ```

5. **If human chooses (c), agent adds to HUMAN_NEEDED.md**:
   ```markdown
   ## H-0123: Hero Background Image Needed
   
   **Feature**: F-0042 (Landing Page)
   **Asset Type**: Image
   **Specifications**:
   - Size: 1920x1080px
   - Theme: Modern tech, blue/purple gradient
   - Style: Abstract, professional
   
   **Suggested Sources**:
   - Unsplash: Search "tech abstract gradient"
   - AI Generation: Prompt provided above
   
   **Blocker**: No (using placeholder for now)
   ```

## License Compliance Rules

### ⚠️ CRITICAL: Always Check Licenses

**Agent MUST**:
1. **NEVER assume an asset is free to use**
2. **ALWAYS verify license before recommending**
3. **ALWAYS add to ATTRIBUTION.md when using external assets**
4. **WARN if license requires attribution**

**License Types Quick Reference**:

| License | Commercial Use | Attribution Required | Modifications Allowed | Notes |
|---------|----------------|----------------------|----------------------|-------|
| **CC0 / Public Domain** | ✅ Yes | ❌ No | ✅ Yes | Best - no restrictions |
| **CC-BY** | ✅ Yes | ✅ Yes | ✅ Yes | Must credit creator |
| **CC-BY-SA** | ✅ Yes | ✅ Yes | ✅ Yes (same license) | Share-alike clause |
| **CC-BY-NC** | ❌ No | ✅ Yes | ✅ Yes | Non-commercial only! |
| **MIT / Apache** | ✅ Yes | ✅ Yes (in LICENSE) | ✅ Yes | Common for code/fonts |
| **OFL (fonts)** | ✅ Yes | ✅ Yes | ✅ Yes | Open Font License |

**🚨 RED FLAGS - DO NOT USE**:
- ❌ CC-BY-NC (Non-Commercial) - unless project is non-commercial
- ❌ CC-BY-ND (No Derivatives) - cannot modify
- ❌ "All Rights Reserved" - not free to use
- ❌ No license specified - UNSAFE, ask human

## Quick Reference for Agents

**When you need an asset**:

1. ✅ Check if it exists in `assets/`
2. ✅ If not, ask human for preference (source/generate/provide)
3. ✅ Provide specific links or generation prompts
4. ✅ ALWAYS check license before recommending
5. ✅ ALWAYS add to ATTRIBUTION.md
6. ✅ Use placeholder if asset not immediately available

**Recommended defaults by asset type**:
- **Images**: Unsplash (no attribution), Pexels (no attribution)
- **Game Sprites**: Kenney.nl (CC0), OpenGameArt.org (check license)
- **Icons**: Heroicons (MIT), Lucide (ISC)
- **Sound Effects**: Freesound.org (check license), Mixkit (no attribution)
- **Music**: Incompetech (CC-BY), Free Music Archive (check license)
- **3D Models**: Poly Haven (CC0), Sketchfab (check license)
- **Fonts**: Google Fonts (OFL)

**When generating with AI**:
- Images: Stable Diffusion (free), DALL-E 3 via Bing (free with limits)
- Sound: AudioCraft (open source), Riffusion (experimental)
