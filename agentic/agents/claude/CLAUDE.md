# Claude instructions

This repo uses the `agentic/` agentic development framework.

## Read first
- `AGENTS.md` (if present)
- `CONTEXT_PACK.md`
- `STATUS.md`
- `spec/OVERVIEW.md`
- `spec/FEATURES.md`
- `spec/NFR.md` (if constraints apply)
- `spec/acceptance/F-####.md` for the feature you are changing
- `/spec/*` and `spec/adr/*`
- `STACK.md` (commands, constraints, testing)

## Follow these rules
- Follow `agentic/agents/shared/agent_operating_guidelines.md`.
- Keep diffs small and test-backed.
- Update `STATUS.md` and keep specs truthful.
