# Agentic Journal - Project History

**Purpose**: Persistent history artifacts that accumulate over the project lifecycle.

This directory separates **persistent history** from **transient state** (`.agentic-state/`).

---

## Contents

| Directory | What | Committed? |
|-----------|------|------------|
| `manifests/` | Change manifests (what changed per feature/branch/date) | Yes |
| `lessons/` | Operational learnings (L-####) | Yes |
| `JOURNAL.md` | Session log (future: move from project root) | Yes |

---

## manifests/

Generated by `bash .agentic/tools/manifest.sh`.

Manifests capture what changed for:
- Features: `manifest.sh F-0042` → `F-0042.json`
- Branches: `manifest.sh --branch feature/foo` → `branch-feature-foo.json`
- Date ranges: `manifest.sh --since 2026-02-01` → `since-2026-02-01.json`
- Explicit commits: `manifest.sh --commits abc,def` → `commits-YYYYMMDD-HHMMSS.json`

Use cases:
- Audit trail: What commits/files implemented a feature?
- Documentation patching: drift.sh uses manifests to detect stale docs
- Code review: What actually changed?

---

## lessons/

Operational learnings captured as L-#### files.

Format: `L-####-short-description.md`

Each lesson captures:
- What happened (the situation)
- Why it happened (root cause)
- What to do next time (action)
- Related features/issues

Use cases:
- Don't repeat mistakes
- Share learnings across sessions
- Build institutional knowledge

---

## Why separate from .agentic-state/?

| `.agentic-state/` | `.agentic-journal/` |
|-------------------|---------------------|
| Transient (WIP, active agents) | Persistent (history) |
| May be gitignored | Always committed |
| Current session state | Accumulated knowledge |

---

## Git tracking

Everything in `.agentic-journal/` is committed:
- Manifests provide audit trail
- Lessons build knowledge base
- Journal documents project evolution

---

## Related tools

- `manifest.sh` - Generate manifests from git history
- `drift.sh --docs --manifest F-####` - Check doc drift against manifest
- `ag done F-####` - Auto-generates manifest on feature completion
